GitHub Desktop 操作

进入 GitHub Desktop

打开后，你会看到：

  1. Sign in toGitHub.com：登录到公开的全球 GitHub 网站（个人项目、开源代码都在这里）。
  2. Sign in to GitHub Enterprise：登录到公司/学校自建的私有 GitHub（内部代码，不对外公开）。**
  3. **New to Github？Create your free account**：这是GitHub 的注册入口，如果你还没有 GitHub 账号，点这里就能免费创建一个。
  4. **Skip this step**：“先跳过登录，直接进入软件”（以后需要 GitHub 时再登录）。【我们这里选择先跳过这一步，后面再说 GitHub。】点击跳过之后，显示下面窗口：

填写用户名和邮箱：设置“代码作者身份”的步骤，你填的姓名和邮箱会永久记录在你提交的代码历史上。这是 Git 的要求，不是 GitHub 的要求**

  • 每次你用 Git 提交代码，都必须附带作者信息（谁写的这段代码）。
  • 这个信息会像“水印”一样打在每一次提交记录里，全球唯一。Name：写你的常用名（英文或拼音）Email：写你常用邮箱（最好与 GitHub 注册邮箱一致），理论上是可以随便写，Git 在技术上不会验证你信息的真假。但最好不要。**
