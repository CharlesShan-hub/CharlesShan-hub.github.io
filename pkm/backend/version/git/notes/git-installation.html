Git 安装

Git 下载与安装

下载地址：https://git-scm.com/

安装没什么可说，按照默认安装即可，一直下一步即可。测试是否安装成功，如果安装成功了，鼠标右键时如下图：**

  1. **Open Git GUI here**：打开图形化 Git 操作界面（老旧工具，不推荐用）。
  2. **Open Git Bash here**：打开Git 命令行窗口（在此文件夹位置执行 Git 命令）。

GUI Clients 下载与安装

GUI Clients 就是 Git 的图形界面客户端。（我们这里选择使用 **GitHub Desktop**）

安装的话没啥可说的，双击直接就打开了。
