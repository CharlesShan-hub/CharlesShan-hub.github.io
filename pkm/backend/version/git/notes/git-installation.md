## Git 下载与安装

**下载地址：**[**https://git-scm.com/**](https://git-scm.com/)

![1766903155491-f0b585cf-2023-4310-bc9a-f7f313fb0f13.png](../assets/1766903155491-f0b585cf-2023-4310-bc9a-f7f313fb0f13.png)

![1766903431257-a7f7b7c9-de85-474a-b9de-70dac3f92a35.png](../assets/1766903431257-a7f7b7c9-de85-474a-b9de-70dac3f92a35.png)

![1766903700692-e3378dd5-1146-42f1-946e-7f410da7ef15.png](../assets/1766903700692-e3378dd5-1146-42f1-946e-7f410da7ef15.png)

**安装没什么可说，按照默认安装即可，一直下一步即可。**测试是否安装成功，如果安装成功了，鼠标右键时如下图：**

![1766906492137-e902d45a-b3b4-4508-8c57-c68e8d5dbd8b.png](../assets/1766906492137-e902d45a-b3b4-4508-8c57-c68e8d5dbd8b.png)

1. `**Open Git GUI here**`**：打开**图形化 Git 操作界面**（老旧工具，不推荐用）。**
2. `**Open Git Bash here**`**：打开**Git 命令行窗口**（在此文件夹位置执行 Git 命令）。**
