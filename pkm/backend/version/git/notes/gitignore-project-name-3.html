## git 的忽略机制

### 为什么需要忽略机制

假设我们开发了一个 java 项目：

```plain

我们的项目/
├── src/           ← 源代码（要保存）
├── target/        ← 编译生成的（不要保存！）
│   ├── classes/   ← .class文件
│   ├── test-classes/
│   └── your-app.jar
├── .idea/         ← IDE配置（不要保存！）
└── .iml           ← 项目文件（不要保存！）

如果没有忽略机制：

  1. Git会把**target/**里的**.class**文件也跟踪（每编译一次，class 都不一样，git 都要对它进行无用的跟踪）
  2. 同事之间的IDE配置互相覆盖。
  3. 仓库里塞满垃圾，提交缓慢。

忽略机制怎么实现

在 git 仓库的根目录下创建一个文件 .gitignore，两个必须：

  1. 必须放在根目录下。
  2. 文件名必须是 .gitignore
