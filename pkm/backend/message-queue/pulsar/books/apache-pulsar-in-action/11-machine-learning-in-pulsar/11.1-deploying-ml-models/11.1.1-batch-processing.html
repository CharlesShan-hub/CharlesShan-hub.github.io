11.1.1 Batch processing

As the name suggests, executing a model in batch processing mode refers to the process where you feed a large batch of data into your model to produce multiple predictions at the same time rather than on a case-by-case basis. These batches of predictions can then be cached and reused as needed.

顾名思义，以批处理模式执行一个模型，指的是这样一个过程：你把一大批数据喂给自己的模型，让它在同一时刻产出多个预测，而不是逐条逐例地来做。这些成批产出的预测随后可以被缓存起来，并在需要时重复使用。

One such example is marketing emails from an e-commerce site that provides a list of product recommendations based on your purchase history with the retailer and what similar customers have purchased. Since these recommendations are based on a historical and slow-changing dataset (i.e., your purchase history) they can be generated at any time. Typically, these marketing emails are generated once per day and delivered to customers based on the customers’ local time zones. Since these recommendations are generated for all customers who haven’t opted out, this is a great candidate for batch processing with the ML model. However, if your recommendations need to factor in the users’ most recent activities, such as the current contents of their shopping cart, then you cannot execute the ML model in batch mode because that data won’t be available. In such a scenario, you will want to deploy your ML model in the near real-time processing mode.

一个典型的例子是某个电商网站发来的营销邮件：它依据你在这家零售商的购买历史、以及相似客户都买了些什么，为你提供一份商品推荐清单。由于这些推荐是基于一个历史性的、变化缓慢的数据集（也就是你的购买历史），它们可以在任何时刻被生成。通常，这类营销邮件每天生成一次，并按照客户各自的本地时区投递给他们。由于这些推荐是面向所有没有选择退订的客户生成的，这是一个用 ML 模型做批处理的绝佳候选场景。然而，如果你的推荐需要把用户最近的活动也纳入考量，例如他们购物车里当前装着些什么，那么你就不能以批处理模式来执行这个 ML 模型了——因为那份数据届时还拿不到。在这种场景下，你会希望以近乎实时的处理模式来部署自己的 ML 模型。
