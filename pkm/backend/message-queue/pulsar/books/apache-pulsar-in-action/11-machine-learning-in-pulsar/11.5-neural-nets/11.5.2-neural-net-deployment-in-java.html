11.5.2 Neural net deployment in Java

2026-10-08book

To execute the Keras model within a Java runtime environment, we’ll use the Deeplearning4J (DL4J) library. It provides functionality for deep learning in Java and can load and utilize models trained with Keras. One of the key concepts to become familiar with when using DL4J is tensors. Java does not have a built-in library for efficient tensor options, which is why I included the NDJ4 library in the Maven dependencies, as shown in the following listing.

为了在 Java 运行时环境中执行这个 Keras 模型，我们将使用 Deeplearning4J（DL4J）库。它提供了在 Java 中进行深度学习的功能，并且能够加载和使用那些用 Keras 训练出来的模型。在使用 DL4J 时，需要熟悉的关键概念之一就是张量（tensor）。Java 并没有一个内置的库来提供高效的张量选项，这正是我把 NDJ4 库加进 Maven 依赖的原因，如下面这份清单所示。

既然我们已经把 DL4J 的各个库配置好了，就可以开始以近乎实时模式来使用这个神经网络了——方法是把它嵌入到一个 Pulsar 函数内部，如下面这份清单所示。

The model object provides predict and output methods. The predict method returns a class prediction (fraud or not fraud), while the output method returns a numeric value representing the exact probability. In this case, we will return the numeric value, so we can evaluate it further (e.g., compare it to a configurable threshold used to define our threshold for fraud).

这个模型对象提供了 predict 和 output 两个方法。predict 方法返回的是一个类别预测（欺诈或非欺诈），而 output 方法返回的是一个代表确切概率的数值。在这里，我们将返回那个数值，以便我们能对它做进一步的评估（例如，把它与我们用来界定欺诈阈值的那个可配置阈值做比较）。
