## 11.4 Delivery time estimation

Now that we have sufficiently covered the background and theory, it is time to see how to deploy an ML model that has been developed and trained by the data science team at GottaEat. A perfect candidate would be the delivery time estimation ML model we have been discussing throughout the chapter. As with any ML model that needs to be deployed to production, the data science team is responsible for providing us with a copy of the trained model to be used.

既然我们已经把背景知识和理论讲得够充分了，那么就该来看看如何部署一个由 GottaEat 数据科学团队开发并训练好的 ML 模型了。一个完美的候选，就是我们贯穿本章一直在讨论的那个送达时间预估 ML 模型。与任何需要被部署到生产环境的 ML 模型一样，数据科学团队有责任为我们提供一份训练好的模型副本以供使用。
