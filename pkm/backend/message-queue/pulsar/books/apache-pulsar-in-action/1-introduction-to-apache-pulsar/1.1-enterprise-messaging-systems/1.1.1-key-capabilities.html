1.1.1 Key capabilities

2026-10-08book

Now that we have introduced the concept of enterprise message systems and provided some context for the types of problems they have been used to solve, let’s further refine the definition of what an EMS is, based upon the capabilities it provides.

既然我们已经介绍了企业消息系统的概念，并说明了它们被用来解决哪几类问题，接下来可以根据 EMS 所提供的能力，进一步细化它的定义。

  • Asynchronous communication

异步通信

Messaging systems allow services and applications to communicate with one another in a non-blocking manner, meaning that the message sender and receiver are not required to interact with the messaging system (or one another) at the same time. A messaging system will retain the messages until all of the intended recipients consume it.

消息系统允许服务与应用以非阻塞的方式相互通信，也就是说，消息的发送方和接收方不必同时与消息系统（或彼此）交互。消息系统会保留这些消息，直到所有预期的接收方都消费了它。

  • Message retention

消息保留

Unlike network-based messaging in which the messages only exist on the network, such as RPC, messages published to a messaging system are retained on disk until they are delivered. Undelivered messages can be held for hours, days, or even weeks, and most messaging systems allow you to specify the retention policy.

与 RPC 这类消息只存在于网络中的基于网络的消息传递不同，发布到消息系统的消息会保留在磁盘上，直到被投递为止。未投递的消息可以保留数小时、数天甚至数周，而且大多数消息系统允许你指定保留策略。

  • Acknowledgment

消息确认

Messaging systems are required to retain messages until all of the intended recipients receive it; therefore, a mechanism by which the message consumers can acknowledge the successful delivery and processing of the message is required. This allows the messaging system to purge all successfully delivered messages and to retry message delivery to those consumers who have not yet received it.

消息系统必须把消息保留到所有预期的接收方都收到为止；因此，需要有一种机制让消息消费者能够确认消息已被成功投递和处理。这样一来，消息系统就可以清除所有已成功投递的消息，并对那些尚未收到的消费者重试投递。

  • Message consumption

消息消费

Obviously, a messaging system isn’t particularly useful if it doesn’t provide a mechanism by which the intended recipients can consume messages. First and foremost, an EMS must guarantee that all the messages it receives get delivered. Oftentimes, a message might be intended for multiple consumers, and the EMS must maintain the information along with which messages have been delivered and to whom.

显然，如果一个消息系统没有提供让预期接收方消费消息的机制，那它就没有太大用处。首先也是最重要的一点，EMS 必须保证它收到的所有消息都会被投递。通常情况下，一条消息可能面向多个消费者，EMS 必须维护哪些消息已经投递、以及投递给了谁这样的信息。
