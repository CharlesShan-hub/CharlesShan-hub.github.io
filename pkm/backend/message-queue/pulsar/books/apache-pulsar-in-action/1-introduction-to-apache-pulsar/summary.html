Summary

  • Apache Pulsar is a modern messaging system that provides both high-performance streaming and traditional queuing messaging.

Apache Pulsar 是一个现代消息系统，同时提供高性能流处理和传统的队列消息。

  • Apache Pulsar provides a lightweight computing engine, Pulsar Functions, which allows developers to implement simple processing logic that is executed against each message and published to a given topic.

Apache Pulsar 提供了一个轻量级计算引擎 Pulsar Functions，使开发者能够实现针对每条消息执行、并发布到给定主题的简单处理逻辑。

  • The benefits of Pulsar’s decoupled storage and serving layers include infinite scalability and zero data loss.

Pulsar 解耦的存储层与服务层所带来的收益包括无限的可扩展性与零数据丢失。

  • Specific use cases where Pulsar has been used in production include IoT analytics, inter-microservice communication, and unified messaging.

Pulsar 已在生产环境中使用的具体用例包括物联网分析、微服务间通信以及统一消息。
