8.3 Message transformation patterns

2026-10-08book

Common examples of streaming data include IoT sensors, server and security logs, real-time advertising, and click-stream data from mobile apps and websites. In each of these scenarios, we have data sources that are continuously generating thousands or millions of unstructured or semi-structured data elements—most commonly, plain text, JSON, or XML. Each of these data elements must be transformed into a format that is suitable for processing and analysis.

流式数据的常见例子包括物联网传感器、服务器与安全日志、实时广告，以及来自移动应用和网站的点击流数据。在上述每一种场景中，我们都面临着这样的数据源：它们在持续不断地生成数千乃至数百万条无结构或半结构化的数据元素——最常见的形态是纯文本、JSON 或 XML。这些数据元素中的每一个，都必须被转换成一种适合处理和分析的格式。

This category of processing is common among all streaming platforms, and these data transformation tasks are similar to traditional ETL processing, since the primary concern is to ensure that the ingested data is normalized, enriched, and transformed into a format more suitable for processing. Message transformation patterns are used to manipulate the content of the messages as they flow through the DAG’s topology to address these types of issues within your streaming architecture. Each of the patterns covered in this section provides proven guidelines for dynamically transforming messages.

这类处理在所有流式平台上都很常见，而这些数据转换任务与传统的 ETL 处理颇为相似，因为其首要关注点都是确保所摄入的数据被规范化、被丰富，并被转换成一种更适合处理的格式。消息转换模式被用来在消息流经 DAG 拓扑的过程中对消息内容加以操控，以解决你的流式架构中的这类问题。本节所讲的每一种模式都提供了经过验证的动态消息转换指导原则。
