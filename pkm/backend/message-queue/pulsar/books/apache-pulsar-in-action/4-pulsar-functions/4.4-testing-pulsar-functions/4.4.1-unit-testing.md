### 4.4.1 Unit testing

The first step would be to write a suite of unit tests that test some of the more common scenarios to validate that the logic is correct and produces accurate results for various sentences we send it. Since this code uses the Pulsar SDK API, we will need to use a mocking library, such as Mockito, to mock the Context object, as shown in the following listing.

第一步是编写一整套单元测试，测试一些较为常见的场景，以验证逻辑是正确的，并且对我们发送给它的各种句子都能产生准确的结果。由于这段代码使用了 Pulsar SDK 的 API，我们需要使用一个 mock 库（例如 Mockito）来 mock 那个 Context 对象，如下面的清单所示。

Listing 4.14 KeywordFilterFunction unit tests

```java
package com.manning.pulsar.chapter4.functions.sdk;

import static org.mockito.Mockito.*;
import static org.junit.Assert.*;

public class KeywordFilterFunctionTests {
private KeywordFilterFunction function = new KeywordFilterFunction();

@Mock
private Context mockedCtx;

@Before
public final void setUp() {
  MockitoAnnotations.initMocks(this);
}

  @Test
  public final void containsKeywordTest() throws Exception {
    when(mockedCtx.getUserConfigValue(
       KeywordFilterFunction.KEYWORD_CONFIG))
       .thenReturn(Optional.of("dog"));                        ❶

 String sentence = "The brown fox jumped over the lazy dog";
 String result = function.process(sentence, mockedCtx);
 assertNotNull(result);                                        ❷
 assertEquals(sentence, result);
  }

  @Test
  public final void doesNotContainKeywordTest() throws Exception {
    when(mockedCtx.getUserConfigValue(
    KeywordFilterFunction.KEYWORD_CONFIG))
    .thenReturn(Optional.of("cat"));                           ❸

    String sentence = "It was the best of times, it was the worst of times";
 String result = function.process(sentence, mockedCtx);
 assertNull(result);                                           ❹
  }

  @Test
  public final void ignoreCaseTest() {
    when(mockedCtx.getUserConfigValue(
       KeywordFilterFunction.KEYWORD_CONFIG))
       .thenReturn(Optional.of("RED"));                        ❺

    when(mockedCtx.getUserConfigValue(
       KeywordFilterFunction.IGNORE_CONFIG))
       .thenReturn(Optional.of(Boolean.TRUE));                 ❻

  String sentence = "Everyone watched the red sports car drive off.";
  String result = function.process(sentence, mockedCtx);
  assertNotNull(result);                                       ❼
  assertEquals(sentence, result);
  }
}
```

❶ Configure the keyword to be dog.

❶ 把关键词配置为 dog。

❷ We expect the sentence to be returned, since it contained the keyword.

❷ 我们预期该句子会被返回，因为它包含了这个关键词。

❸ Configure the keyword to be cat.

❸ 把关键词配置为 cat。

❹ We don’t expect the sentence to be returned, since it did not contain the keyword.

❹ 我们不预期该句子会被返回，因为它不包含这个关键词。

❺ Configure the keyword to be RED.

❺ 把关键词配置为 RED。

❻ Configure the function to ignore case when filtering on the keyword.

❻ 把该函数配置为在按关键词过滤时忽略大小写。

❼ We expect the sentence to be returned, since it contained a lowercase version of the keyword.

❼ 我们预期该句子会被返回，因为它包含了该关键词的小写形式。

As you can see, these unit tests cover the very basic functionality of the function and rely on the use of a mock object for the Pulsar context object. This type of test suite is just like one you would write to test any Java class that wasn’t a Pulsar function.

正如你所看到的，这些单元测试覆盖了该函数最基本的功能，并且依赖使用一个 mock 对象来替代 Pulsar 的 context 对象。这种类型的测试套件，与你在测试任何一个并非 Pulsar function 的 Java 类时会写的测试套件并无二致。
