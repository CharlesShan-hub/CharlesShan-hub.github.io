4.3 Developing Pulsar functions

2026-10-08book

Pulsar functions can currently be written in Java, Python, and Go. Therefore, if you are already familiar with any of these popular languages, you will be able to develop Pulsar functions relatively quickly.

Pulsar function 目前可以用 Java、Python 和 Go 编写。因此，如果你已经熟悉这些流行语言中的任何一种，就能够相当快地开发出 Pulsar function。
