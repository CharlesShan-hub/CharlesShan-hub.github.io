### 4.3.1 Language native functions

Pulsar supports what are commonly referred to as *language-native functions*, which means *no* Pulsar-specific libraries or special dependencies are required. The benefit of language-native functions is that they don’t have any dependencies beyond what’s already available in the programming language itself, which makes them extremely lightweight and easy to develop. Currently, language-native functions can only be developed using Java or Python. Golang support for this feature is not yet available.

Pulsar 支持通常被称为*语言原生函数（language-native function）*的东西，这意味着*不需要*任何 Pulsar 专属的库或特殊的依赖项。语言原生函数的好处在于，除了编程语言本身已经提供的东西之外，它们没有任何其他依赖，这使它们极为轻量且易于开发。目前，语言原生函数只能用 Java 或 Python 来开发。该特性对 Golang 的支持尚不可用。

Java language native functions

Java 语言原生函数

In order for a piece of Java code to be used as a language-native function, it must implement the java.util.Function interface, which has just a single apply method, as shown in listing 4.1. While this simplistic function merely echoes back any string value it receives, it does demonstrate just how easy it is to develop a function using only features of the Java language itself. Any sort of complex logic can be included inside the apply method to provide more robust stream-processing capabilities.

要让一段 Java 代码被用作语言原生函数，它必须实现 java.util.Function 接口，该接口只有一个 apply 方法，如清单 4.1 所示。虽然这个极简的函数只是把它收到的任何字符串原样返回，但它确实展示了：仅使用 Java 语言本身的特性来开发一个函数是多么容易。任何种类的复杂逻辑都可以被放进 apply 方法内部，以提供更强大的流处理能力。

Listing 4.1 Java-native function

```java
import java.util.Function;

public class EchoFunction implements Function
<String, String> {                            ❶

   public String apply(String input) {        ❷
   return input;
}
}
```

❶ Specifies that the input topic content will be a string and that we will return a string

❶ 指定输入主题的内容将是一个字符串，并且我们将返回一个字符串

❷ The only method defined in the function interface, which is executed when a message is received

❷ 该函数接口中定义的唯一方法，在收到消息时被执行

Python language-native functions

Python 语言原生函数

For a piece of Python code to be used as a language-native function, it must have a method named process, like the functions shown in the following listing, that merely appends an exclamation point to any string value it receives.

要让一段 Python 代码被用作语言原生函数，它必须有一个名为 process 的方法，就像下面清单中所示的函数那样——它只是在收到的任何字符串值后面追加一个感叹号。

Listing 4.2 Python-native function

```python
def process(input):                   ❶
    return "{}!".format(input)        ❷
```

❶ The method that gets called when a message arrives

❶ 消息到达时被调用的方法

❷ Returns the provided input with an exclamation point appended to the end

❷ 返回所提供的输入，并在末尾追加一个感叹号

As you can see, the language-native approach provides a clean, API-free way of writing Pulsar functions. It is ideal for the development of simple, stateless functions.

正如你所看到的，语言原生的方式提供了一种干净、不依赖 API 的方式来编写 Pulsar function。它非常适合开发简单的、无状态的函数。
