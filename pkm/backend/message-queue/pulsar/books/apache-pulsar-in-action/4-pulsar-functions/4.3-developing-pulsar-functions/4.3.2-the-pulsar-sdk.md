### 4.3.2 The Pulsar SDK

Another option is to develop your functions using the Pulsar Functions SDK, which leverages Pulsar-specific libraries that provide a range of functionality not available in the native interfaces, such as state management and user configuration. Additional capabilities and information can be accessed through a Context object that is defined inside the SDK, including

另一种选择是使用 Pulsar Functions SDK 来开发你的函数，它利用 Pulsar 专属的库，提供了原生接口所不具备的一系列功能，例如状态管理和用户配置。更多能力和信息可以通过 SDK 内部定义的一个 Context 对象来访问，其中包括

- The name, version, and ID of the Pulsar function

  Pulsar function 的名称、版本和 ID

- The message ID of each message

  每条消息的消息 ID

- The name of the topic on which the message was sent

  消息被发送到的主题的名称

- The names of all input topics as well as the output topic associated with the function

  该函数关联的所有输入主题以及输出主题的名称

- The tenant and namespace associated with the function

  该函数关联的租户和命名空间

- The logger object used by the function, which can be used to write log messages

  该函数所使用的 logger 对象，可用于写入日志消息

- Access to arbitrary user config values supplied via the CLI

  访问通过 CLI 提供的任意用户配置值

- An interface for recording metrics

  用于记录指标的接口

An implementation of the Pulsar SDK is available for Java, Python, and Golang, and each specifies a functional interface that includes the Context object as a parameter that is populated and provided by the Pulsar Functions runtime environment.

```java
@FunctionalInterface
```

The process method is called at least once, depending on the processing guarantees you specify for the function for every message that is published to the configured input topic of the function. The incoming input bytes are serialized to the input type I for JSON-based messages as well as simple Java types, such as String, Integer, and Float. If these types do not meet your needs, you can also use your own types as long as you provide your own implementation of the org.apache.pulsar.functions.api .SerDe interface for the type, or you can register the incoming message type in the Pulsar schema registry, which I will cover in greater detail in chapter 7. An implementation of the echo function that demonstrates several different features of the SDK, such as logging and recording metrics, is shown in the following listing.

对于发布到该函数所配置的输入主题上的每一条消息，process 方法至少会被调用一次，具体次数取决于你为该函数指定的处理保证。对于基于 JSON 的消息，以及 String、Integer、Float 等简单 Java 类型，传入的输入字节会被序列化为输入类型 I。如果这些类型不能满足你的需要，你也可以使用自己的类型，前提是你为该类型提供了自己对 org.apache.pulsar.functions.api.SerDe 接口的实现；或者你也可以在 Pulsar schema 注册表中注册传入的消息类型，我将在第 7 章更详细地讨论这一点。下面清单中展示的这个 echo 函数实现，演示了 SDK 的若干不同特性，例如记日志和记录指标。

Listing 4.5 Pulsar SDK function in Java

```java
import java.util.stream.Collectors;
import org.apache.pulsar.functions.api.Context;
import org.apache.pulsar.functions.api.Function;              ❶
import org.slf4j.Logger;

public class EchoFunction implements Function<String, String> {

    public String process(String input, Context ctx) {         ❷
       Logger LOG = ctx.getLogger();                           ❸
       String inputTopics =
         ctx.getInputTopics().stream()
            .collect(Collectors.joining(", "));               ❹

       String functionName = ctx.getFunctionName();            ❺

       String logMessage =
           String.format("A message with a value of \"%s\" +
                “has arrived on one of the following topics: %s\n",
                input, inputTopics);

        LOG.info(logMessage);                                  ❻
        String metricName =
           String.format("function-%s-messages-received", functionName);

        ctx.recordMetric(metricName, 1);                       ❼
        return input;
    }
}
```

The Java SDK’s context object enables you to access key/value pairs provided to the Pulsar function via the command line (as JSON). This feature allows you to write generic functions that can be used multiple times but with a slightly different configuration. For instance, let’s say you want to write a function that filters events based on a user-defined regular expression. When an event arrives, the contents are compared to the configured regex, and those entries that match the provided pattern are returned, and all others are ignored. Such a function could be useful if you want to verify the format of the incoming data before you begin processing it. An example of such a function that accesses the regular expression from the key/value pairs in the context object is shown in the following listing.

Java SDK 的 context 对象使你能够访问通过命令行（以 JSON 形式）提供给该 Pulsar function 的键/值对。这一特性允许你编写通用的函数，它们可以被多次使用，只是配置略有不同。举例来说，假设你想编写一个根据用户定义的正则表达式来过滤事件的函数。当一个事件到达时，把它与配置好的正则表达式进行比较，匹配所提供模式的那些条目被返回，其余的全部被忽略。如果你希望在开始处理传入数据之前先校验其格式，这样的函数就会很有用。下面清单展示了这样一个函数的示例，它从 context 对象的键/值对中取出那个正则表达式。

Listing 4.6 User-configured Pulsar function in Java

```java
import java.util.regex.Pattern;
import org.apache.pulsar.functions.api.Context;
import org.apache.pulsar.functions.api.Function;

public class RegexMatcherFunction implements Function<String, String> {

    public static final String REGEX_CONFIG = "regex-pattern";

    @Override
    public String process(String input, Context ctx) throws Exception {
        Optional<Object> config =
          ctx.getUserConfigValue(REGEX_CONFIG);                    ❶

        if (config.isPresent() && config.get().getClass()
             .getName().equals(String.class.getName())) {          ❷

           Pattern pattern = Pattern.compile(config.get().toString());
           if (pattern.matcher(input).matches()) {                 ❸
               String metricName =
                 String.format("%s-regex-matches",ctx.getFunctionName());

               ctx.recordMetric(metricName, 1);
               return input;
           }
        }
       return null;                                                ❹
    }
}
```

❶ Retrieve the regex pattern from the user-provided configs.

❶ 从用户提供的配置中取出正则表达式模式。

❷ If a regex string was provided, then compile the regex.

❷ 如果提供了一个正则表达式字符串，就编译它。

❸ If the input matches the regex, allow it to pass.

❸ 如果输入与该正则表达式匹配，就放行。

❹ Otherwise, return null.

❹ 否则返回 null。

Pulsar Functions can publish results to an output topic, but this isn’t required. You can also have functions that don’t always return a value, such as the function in listing 4.5 that filters out non-matching inputs. In such a scenario, you can simply return a value of null from the function.

Pulsar Functions 可以把结果发布到输出主题，但这并不是必需的。你也可以让函数不总是返回值，例如清单 4.5 中那个过滤掉不匹配输入的函数。在这种场景下，你只需从函数中返回一个 null 值即可。

When writing Golang-based functions, remember that you need to provide the name of the function you wish to perform the actual logic to the pf.Start() method inside the main() method call, as shown in listing 4.8. This registers the function with the Pulsar Functions framework and ensures that the specified function is the one that is invoked when a new message arrives. In this case, we named used the echoFunc function, but it can be named anything, provided that the method signature matches any of the supported ones shown in the following listing. Any other function signatures will not be accepted, and consequently, no processing logic will be executed inside your Golang function.

在编写基于 Golang 的函数时，请记住：你需要在 main() 方法的调用中，把你希望执行实际逻辑的那个函数的名字传给 pf.Start() 方法，如清单 4.8 所示。这会把该函数注册到 Pulsar Functions 框架，并确保当新消息到达时被调用的就是这个指定的函数。在本例中，我们使用的名字是 echoFunc，但它可以是任何名字，只要其方法签名匹配下面清单中所示任一受支持的签名即可。任何其他函数签名都不会被接受，因此你的 Golang 函数内部也不会有任何处理逻辑被执行。


There are currently some limitations when it comes to using the SDK to develop Golang-based Pulsar functions, but this is subject to change as the project matures, so I highly recommend checking the most recent version of the online documentation for the latest capabilities. However, as of the writing of this book, Golang functions do not support the recording of function-level metrics (e.g., there isn’t a recordMetric method defined inside the context object of the Golang SDK). Furthermore, you cannot implement stateful functions using Golang at this time.

在使用 SDK 开发基于 Golang 的 Pulsar function 时，目前存在一些限制；但随着项目走向成熟，这一点可能会有变化，因此我强烈建议你查阅最新版本的在线文档，以了解最新的能力。不过，就本书写作时而言，Golang 函数不支持记录函数级指标（例如，Golang SDK 的 context 对象中没有定义 recordMetric 方法）。此外，目前你也无法用 Golang 实现有状态函数。
