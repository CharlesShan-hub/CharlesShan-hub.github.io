2.2 Pulsar’s logical architecture

2026-10-08book

Like other messaging systems, Pulsar uses the concept of topics to denote message channels for transmitting data between producers and consumers. However, the way in which these topics are named is different in Pulsar than in other messaging systems. In the following sections, I will cover the underlying logical structure that Pulsar uses for storing and managing topics.

与其他消息系统一样，Pulsar 使用主题这一概念来表示在生产者与消费者之间传输数据的消息通道。不过，Pulsar 中这些主题的命名方式与其他消息系统不同。在接下来的几节中，我将介绍 Pulsar 用于存储和管理主题所采用的底层逻辑结构。
