### 5.3.1 Unit testing

The first step is to write a suite of unit tests that test some of the more common scenarios in order to validate that the logic is correct and produces accurate results for various sentences we send it. Since this code uses the Pulsar SDK API, we will need to use a Mocking library, such as Mockito, to mock the SourceContext object, as shown in the following listing.

第一步是编写一整套单元测试，测试一些较为常见的场景，以验证逻辑是正确的，并且对我们发送给它的各种句子都能产生准确的结果。由于这段代码使用了 Pulsar SDK 的 API，我们需要使用一个 Mock 库（例如 Mockito）来 mock 那个 SourceContext 对象，如下面的清单所示。

As you can see, these unit tests cover the very basic functionality of Functions and rely on the use of a mock object for the Pulsar context object. This type of test suite is quite similar to one you would write to test any Java class that wasn’t a Pulsar function.

正如你所看到的，这些单元测试覆盖了 Functions 最基本的功能，并且依赖使用一个 mock 对象来替代 Pulsar 的 context 对象。这种类型的测试套件，与你在测试任何一个并非 Pulsar function 的 Java 类时会写的测试套件非常相似。
