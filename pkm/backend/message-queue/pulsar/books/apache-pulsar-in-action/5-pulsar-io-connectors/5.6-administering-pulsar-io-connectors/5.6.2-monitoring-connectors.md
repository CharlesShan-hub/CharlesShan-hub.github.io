### 5.6.2 Monitoring connectors

Another useful command for monitoring Pulsar IO connectors is the pulsar-admin sink status command. This command will return runtime information about the specified connector, such as how many instances are running and if any of the instances have encountered errors.

另一个用于监控 Pulsar IO 连接器的实用命令是 pulsar-admin sink status。该命令会返回指定连接器的运行时信息，例如当前有多少个实例在运行，以及是否有实例遇到了错误。

Listing 5.26 Output of the Sink status command

```bash
docker exec -it pulsar /pulsar/bin/pulsar-admin sink status \
 --name mongo-test-sink
{
  "numInstances" : 1,                                         ❶
  "numRunning" : 1,                                           ❷
  "instances" : [ {                                           ❸
    "instanceId" : 0,
    "status" : {
      "running" : true,                                       ❹
      "error" : "",                                           ❺
      "numRestarts" : 0,                                      ❻
      "numReadFromPulsar" : 0,                                 ❼
      "numSystemExceptions" : 0,
      "latestSystemExceptions" : [ ],
      "numSinkExceptions" : 0,
      "latestSinkExceptions" : [ ],
      "numWrittenToSink" : 0,    
      "lastReceivedTime" : 0,                                  ❽
      "workerId" : "c-standalone-fw-d513daf5b94e-8080"
    }
  } ]
}
```

❶ The total number of instances of the connector that were requested

❶ 该连接器被请求的实例总数。

❷ The total number of instances of the connector that are running

❷ 该连接器当前正在运行的实例总数。

❸ An array of information for each instance

❸ 每个实例对应的一组信息，构成一个数组。

❹ The current status of the connector

❹ 连接器当前的状态。

❺ Any applicable error messages

❺ 任何相关的错误消息。

❻ The number of times the connector attempted to restart. This number increases whenever the connector failed to start, and it is relaunched.

❻ 连接器尝试重启的次数。每当连接器启动失败并被重新启动时，这个数字就会增加。

❼ The number of messages consumed from the Pulsar input topic by this instance

❼ 该实例从 Pulsar 输入主题消费的消息数量。

❽ The last time an incoming message was consumed by this instance

❽ 该实例上一次消费到传入消息的时间。

As you can see from listing 5.26, the pulsar-admin sink status command would be particularly useful for checking on the status of a connector immediately after you have deployed it to make sure it started properly. The pulsar-admin sink get command can be used to return the configuration information about a Pulsar IO connector, which is useful when you want to inspect the configuration settings of your connector to ensure it is properly configured, as shown in the next listing.

正如你从清单 5.26 中所见，pulsar-admin sink status 命令在刚部署完连接器之后立即检查其状态、确认它是否正常启动这一场景下尤其有用。pulsar-admin sink get 命令则可用于返回某个 Pulsar IO 连接器的配置信息；当你想检查连接器的配置设置、确认它配置正确时，这个命令就会派上用场，如下一个清单所示。

Listing 5.27 Output of the sink get command

```bash
docker exec -it pulsar /pulsar/bin/pulsar-admin sink get \
--name mongo-test-sink
{
  "tenant": "public",
  "namespace": "default",
  "name": "mongo-test-sink",                                      ❶
  "className": "org.apache.pulsar.io.mongodb.MongoSink",          ❷
  "inputSpecs": {
    "test-mongo": {                                               ❸
      "isRegexPattern": false                                     ❹
    }
  },
  "configs": {                                                    ❺
    "mongoUri": "mongodb://mongodb:27017/admin",
    "database": "pulsar_in_action",
    "collection": "example",
    "batchSize": "1.0",
    "batchTimeMs": "1000.0"
  },
  "parallelism": 1,                                               ❻
  "processingGuarantees": "ATLEAST_ONCE",
  "retainOrdering": false,
  "autoAck": true,
  "archive": "builtin://mongo"
}
```

❶ The tenant, namespace, and name of the connector

❶ 连接器的租户、命名空间和名称。

❷ The classname of the connector implementation

❷ 连接器实现类的类名。

❸ The input topics for the sink connector

❸ 该 sink 连接器的输入主题。

❹ Whether or not the sink is configured to consume from multiple topics based on some regular expression

❹ 该 sink 是否配置为基于某个正则表达式从多个主题消费。

❺ All of the user-defined configuration properties we provided in the sink-config-file

❺ 我们在 sink-config-file 中提供的所有用户自定义配置属性。

❻ All of the default property values for properties we did not specify

❻ 我们未指定的那些属性所对应的默认值。

What makes this command even more useful is the fact that the output of the command is a properly formatted JSON connector configuration that can be saved as a file, modified, and used to update the configuration of the running connector with the update command. This frees you from having to retain a copy of the configuration you deployed a specific connector with, as the data can easily be retrieved from the running connector with this command.

让这个命令更加有用的一点是：它的输出本身就是一段格式规范的 JSON 连接器配置，你可以把它保存成文件、加以修改，然后用 update 命令来更新正在运行的那个连接器的配置。这样一来，你就不必再单独保留一份当初部署该连接器时所用的配置副本了——因为用这条命令随时都能从运行中的连接器上轻松取回这些数据。

Listing 5.28 Updating the Mongo DB connector

```bash
/pulsar/bin/pulsar-admin sink update \
   --sink-type mongo \
   --sink-config-file /pulsar/examples/mongodb-sink.yml \
   --inputs prod-mongo \
   --processing-guarantees EFFECTIVELY_ONCE
```

The pulsar-admin sink update command allows you to dynamically change the configuration parameters of an already-submitted sink connector without having to delete and re-create it. The update command takes in a variety of command-line options, which are described in greater detail in the Apache documentation (pulsar.apache.org/docs/en/pulsar-admin/), that allow you to change almost any of the connector’s configurations, including the archive file if you wanted to deploy a new version of the connector. This makes modifying, testing, and deploying a much more streamlined process. Listing 5.28 shows how to update the Mongo sink connector we deployed earlier to use a different Pulsar topic as the input source and change the processing guarantees.

pulsar-admin sink update 命令允许你动态修改一个已提交的 sink 连接器的配置参数，而不必先删除再重新创建它。update 命令接受多种命令行选项（Apache 文档 pulsar.apache.org/docs/en/pulsar-admin/ 中有更详细的说明），借助这些选项，你几乎可以更改连接器的任何配置项——包括归档文件本身，如果你想部署该连接器的新版本的话。这让修改、测试和部署的流程变得更加顺畅。清单 5.28 展示了如何更新我们之前部署的那个 Mongo sink 连接器：改用另一个 Pulsar 主题作为输入源，并更改其处理保证级别。
