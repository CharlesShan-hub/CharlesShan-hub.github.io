5.5 Pulsar’s built-in connectors

Pulsar provides a wide variety of existing sources and sinks, collectively referred to as built-in connectors, that you can use to get started using the Pulsar IO connector framework without having to write any code. Pulsar releases all the built-in connectors as individual archives. All that is required to use these connectors is a copy of the built-in connector’s archive (NAR) file on your Pulsar cluster and a simple YAML or JSON configuration file that specifies the runtime parameters used to connect to the external system. If you are running Pulsar in standalone mode, as we are by using the Pulsar standalone Docker image, then these built-in connectors’ individual archives are already included as part of the distribution.

Pulsar 提供了种类繁多的现有 source 和 sink，它们被统称为内置连接器（built-in connector）。借助这些连接器，你无需编写任何代码就能上手使用 Pulsar IO 连接器框架。Pulsar 以独立的归档文件形式发布所有内置连接器。要使用某个连接器，只需要两样东西：一是把该内置连接器的归档（NAR）文件放到 Pulsar 集群上，二是准备一个简单的 YAML 或 JSON 配置文件，用来指定连接外部系统时所需的运行时参数。如果你像我们一样，使用 Pulsar 独立模式（standalone）的 Docker 镜像来运行 Pulsar，那么这些内置连接器的独立归档文件已经作为发行版的一部分包含在内了。

Let’s walk through a simple scenario that uses these built-in connectors to move data from Pulsar into MongoDB. While this example is a bit simplistic in nature, it will demonstrate how easy it is to use the connector’s framework and help demonstrate some of the high-level steps required to deploy and use Pulsar IO connectors. The first step in this process will be to create an instance of MongoDB that we can interact with.

下面我们来看一个简单的场景：使用这些内置连接器把数据从 Pulsar 搬进 MongoDB。虽然这个例子本身有些简单，但它能展示连接器框架用起来有多么容易，也有助于演示部署和使用 Pulsar IO 连接器所需的一些高层步骤。这个流程的第一步，是创建一个可供我们操作的 MongoDB 实例。
