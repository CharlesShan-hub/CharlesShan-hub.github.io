### 5.5.2 Link the Pulsar and MongoDB containers

Since we are going to run the MongoDB Pulsar connector inside the Pulsar Docker container, there must be network connectivity between the two containers. The easiest way to accomplish this in Docker is by using the --link command line argument when launching the Pulsar container. However, since we already started the Pulsar container, we will first need to stop it and remove it before restarting it with the --link switch. Therefore, you will need to execute all of the commands shown in the following listing before proceeding.

由于我们要在 Pulsar Docker 容器内部运行 MongoDB Pulsar 连接器，这两个容器之间必须存在网络连通性。在 Docker 中实现这一点最简单的方式，是在启动 Pulsar 容器时使用 --link 命令行参数。不过，由于我们已经启动了 Pulsar 容器，所以需要先把它停掉并删除，再带上 --link 开关重新启动。因此，在继续之前，你需要执行下面清单中列出的全部命令。

Listing 5.19 Commands to link Pulsar and MongoDB containers

```bash
$ docker stop pulsar                                            ❶

$ docker rm pulsar                                              ❷

$ docker run -d \
  -p 6650:6650 -p 8080:8080 \
  -v $PWD/data:/pulsar/data \
  --name pulsar \
  --link mongodb \                                            ❸
  apachepulsar/pulsar-standalone

$ docker exec -it pulsar bash                                   ❹

apt-get update && apt-get install vim --fix-missing -y          ❺
vim /pulsar/examples/mongodb-sink.yml                           ❻
```

❶ Stops the currently running Pulsar container

❶ 停止当前正在运行的 Pulsar 容器。

❷ Deletes the old Pulsar container, so we can create a new one with the same name

❷ 删除旧的 Pulsar 容器，以便我们能创建一个同名的新容器。

❸ Links the MongoDB container to the Pulsar container

❸ 把 MongoDB 容器链接到 Pulsar 容器。

❹ Exec into the new Pulsar container

❹ 进入新的 Pulsar 容器内部执行命令。

❺ We need to install the vim text editor in the Pulsar container so we can edit the config file.

❺ 我们需要在 Pulsar 容器中安装 vim 文本编辑器，这样才能编辑配置文件。

❻ Launch the text editor inside the Pulsar container to create the configuration file.

❻ 在 Pulsar 容器内部启动文本编辑器来创建配置文件。

By providing the name of the container running the MongoDB instance we wish to interact with in the --link switch, Docker creates a secure network channel between the two containers that allows the Pulsar container to talk to the MongoDB container via the link name. We will see this when we configure the MongoDB sink connector.

在 --link 开关中给出我们希望交互的那个 MongoDB 实例所在容器的名称，Docker 就会在两个容器之间建立一条安全的网络通道，使 Pulsar 容器能够经由该链接名与 MongoDB 容器通信。稍后配置 MongoDB sink 连接器时，我们就会看到这一点。
