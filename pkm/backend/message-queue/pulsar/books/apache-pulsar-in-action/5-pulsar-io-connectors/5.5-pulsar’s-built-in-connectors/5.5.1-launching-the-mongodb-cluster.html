5.5.1 Launching the MongoDB cluster

2026-10-08book

The following command will run the latest MongoDB container in detached mode for us. We are also mapping the container ports with host ports, so we can access the database from our local machine if we want to. Once the container has launched, we will have a functional MongoDB deployment available for us to work with:

下面这条命令会以分离（detached）模式为我们运行最新版 MongoDB 容器。我们还把容器端口映射到宿主机端口，这样如果需要，就能从本地机器访问这个数据库。容器启动完成后，我们就拥有了一个可用的 MongoDB 部署环境：

$ docker run -d \
  -p 27017-27019:27017-27019 \
  --name mongodb \
  mongo

At this point we will have a MongoDB Docker container currently running in detached mode. Next, you will need to execute the mongo command to launch the MongoDB shell client. Once inside the shell we will need to create a new database and collection to store the data. Next, we will need to create a new database named pulsar_in_action and define a collection inside the database that we will use for storing the data, using the commands shown in following listing.

此时我们已经有一个以分离模式运行的 MongoDB Docker 容器。接下来，你需要执行 mongo 命令来启动 MongoDB shell 客户端。进入 shell 之后，我们需要创建一个新的数据库和集合来存放数据。具体来说，我们要创建一个名为 pulsar_in_action 的新数据库，并在其中定义一个用于存放数据的集合，所使用的命令如以下清单所示。

Listing 5.18 Creating a Mongo database table

docker exec -it mongodb mongo                                   ❶

❶ Start the MongoDB interactive shell.

❶ 启动 MongoDB 交互式 shell。

❷ Among the output, you should see the MongoDB shell version.

❷ 在输出内容中，你应该能看到 MongoDB shell 的版本号。

❸ Creates a database with the name pulsar_in_action

❸ 创建一个名为 pulsar_in_action 的数据库。

❹ Creates a collection named example inside the database and defines the schema

❹ 在该数据库中创建一个名为 example 的集合，并定义其 schema。

❺ Query the database to confirm the record was added successfully.

❺ 查询该数据库，确认记录已成功添加。

Now that we have a MongoDB cluster running locally and a database created, we can proceed with configuring a MongoDB sink connector. It will then read messages from a Pulsar topic and write the messages into a MongoDB table we created.

现在本地已经有一个运行中的 MongoDB 集群，数据库也创建好了，接下来就可以着手配置 MongoDB sink 连接器了。它会从 Pulsar 主题读取消息，并把这些消息写入我们刚创建的 MongoDB 表中。
