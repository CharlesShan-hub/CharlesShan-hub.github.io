## 3.1 Getting started with Pulsar

For the purposes of local development and testing, you can run Pulsar on your development machine within a Docker container. If you don’t already have Docker installed, you should download the community edition (https://www.docker.com/ community-edition) and follow the instructions for your operating system. For those of you unfamiliar with Docker, it is an open source project for automating the deployment of applications as portable, self-contained images that can be run from a single command. Each Docker image bundles all the separate software components necessary to run an entire application together into a single deployment. For example, the Docker image for a simple web application would include the web server, database, and application code—in short, everything the application needs to run. Similarly, there is an existing Docker image that includes a Pulsar broker as well as the necessary ZooKeeper and BookKeeper components.

出于本地开发与测试的目的，你可以在自己的开发机上用 Docker 容器来运行 Pulsar。如果你还没有安装 Docker，应当下载社区版（https://www.docker.com/community-edition）并按照适用于你操作系统的说明进行安装。对于不熟悉 Docker 的读者：它是一个开源项目，用于把应用的部署自动化为可移植、自包含的镜像，这些镜像可以通过单条命令运行。每个 Docker 镜像都把运行整个应用所需的各个独立软件组件打包在一起，形成一次单一的部署。例如，一个简单 Web 应用的 Docker 镜像会包含 Web 服务器、数据库和应用代码——简而言之，包含该应用运行所需的一切。类似地，也有一个现成的 Docker 镜像，其中既包含了 Pulsar broker，也包含了必需的 ZooKeeper 和 BookKeeper 组件。

Software developers can create Docker images and publish them to a central repository known as Docker Hub. You can specify a tag when uploading an image that uniquely identifies it. This allows people to quickly locate and download the desired version of the image to their development machines.

软件开发者可以创建 Docker 镜像，并把它们发布到一个被称为 Docker Hub 的中央仓库。在上传镜像时，你可以指定一个标签来唯一标识它。这使人们能够快速定位并下载他们想要的镜像版本到自己的开发机上。

To start the Pulsar Docker container, simply execute the command shown in listing 3.1, which will download the container image and start all the necessary components. Note that we have specified a pair of ports (6650 and 8080) that will be exposed on your local machine. You will use these ports to interact with the Pulsar cluster later in the chapter.

要启动 Pulsar 的 Docker 容器，只需执行清单 3.1 中所示的命令，它会下载该容器镜像并启动所有必需的组件。请注意，我们指定了一对端口（6650 和 8080），它们将暴露在你的本地机器上。在本章后面的部分，你会用这些端口与 Pulsar 集群交互。

Listing 3.1 Running Pulsar on your desktop

```bash
docker pull apachepulsar/pulsar-standalone     ❶

docker run -d \
  -p 6650:6650 -p 8080:8080 \                  ❷
  -v $PWD/data:/pulsar/data \                  ❸
  --name pulsar \                              ❹
  apachepulsar/pulsar-standalone               ❺
```

❶ Pull down the latest version from DockerHub.

❶ 从 DockerHub 拉取最新版本。

❷ Configure port forwarding for these ports.

❷ 为这些端口配置端口转发。

❸ Retain the data on a local drive.

❸ 把数据保留在本地磁盘上。

❹ Specify the name of the container.

❹ 指定容器的名称。

❺ The tag for the standalone image

❺ standalone 镜像的标签

If Pulsar has successfully started, you should be able to locate INFO-level messages in the log file of the Pulsar container indicating that the messaging service is ready, like those shown in the following listing. You can access the Docker log files via the docker log command, which allows you to locate any issues if your container fails to start.

如果 Pulsar 已成功启动，你应该能够在 Pulsar 容器的日志文件中找到 INFO 级别的消息，表明消息服务已就绪，就像下面这个清单中所示的那样。你可以通过 docker log 命令访问 Docker 的日志文件，这样在容器启动失败时就能定位问题。

Listing 3.2 Verifying that the Pulsar cluster is running

```text
$docker logs pulsar | grep "messaging service is ready"

20:11:45.834 [main] INFO  org.apache.pulsar.broker.PulsarService - messaging service is ready
20:11:45.855 [main] INFO  org.apache.pulsar.broker.PulsarService -
messaging service is ready, bootstrap service port = 8080,
broker url= pulsar://localhost:6650, cluster=standalone
```

These log messages indicate that the Pulsar broker is up and running and accepting connections on port 6650 of your local development machine. Therefore, all the code examples in this chapter will use the pulsar://localhost:6650 URL to send and receive data from the Pulsar broker.

这些日志消息表明 Pulsar broker 已启动并在运行，正在你本地开发机的 6650 端口上接受连接。因此，本章中的所有代码示例都将使用 pulsar://localhost:6650 这个 URL 来与 Pulsar broker 收发数据。
