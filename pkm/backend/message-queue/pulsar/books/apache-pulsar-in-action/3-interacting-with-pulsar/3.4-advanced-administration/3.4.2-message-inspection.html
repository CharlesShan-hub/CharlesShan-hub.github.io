3.4.2 Message inspection

Sometimes you may want to view the contents of a particular message or group of messages within a Pulsar topic. Consider the scenario where one of the message producers changes the output format of its messages by encrypting the message contents. Consumers that are currently subscribed to the topic would suddenly start encountering exceptions when they attempt to process these encrypted contents, which would result in the messages not getting acknowledged. Eventually, these messages would accumulate on the topic, since they never get acknowledged. If the change to the producer code was not coordinated with you, then you will be unaware of the underlying issue. Fortunately, you can use the peek-messages command of the pulsar-admin CLI tool to view the raw bytes of the messages inside a given subscription, as shown in the following listing, which shows the syntax for peeking at the last 10 messages for the subscription example-sub on the persistent://manning/chapter03/example-topic.

有时你可能希望查看 Pulsar 主题中某条或某组消息的内容。考虑这样一个场景：某个消息生产者通过加密消息内容，改变了其消息的输出格式。当前订阅了该主题的消费者在尝试处理这些加密内容时会突然开始遇到异常，这将导致这些消息无法被确认。最终，这些消息会在主题上不断累积，因为它们永远不会被确认。如果生产者代码的这一改动没有与你协调过，你就不会察觉到背后的这个问题。所幸的是，你可以使用 pulsar-admin CLI 工具的 peek-messages 命令来查看某个给定订阅内消息的原始字节，如下面的清单所示；该清单展示了在 persistent://manning/chapter03/example-topic 上查看订阅 example-sub 的最后 10 条消息的语法。
