# Windows快捷键

## 窗口管理

| 快捷键           | 功能        |
| :------------ | :-------- |
| **Win + D**   | 显示桌面      |
| **Win + E**   | 打开文件资源管理器 |
| **Win + R**   | 打开运行窗口    |
| **Win + L**   | 锁屏        |
| **Alt + Tab** | 应用之间的切换   |


## 文本编辑

| 快捷键 | 功能 |
| :--- | :--- |
| **home** | 光标回到行首 |
| **end** | 光标移动到行尾 |
| **ctrl + shift + left** | 选中到单词开头 |
| **ctrl + shift + right** | 选中到单词结尾 |
