Java转义字符

什么是转义字符

转义字符是以反斜杠\开头的特殊字符序列，用于表示一些无法直接输入的字符或具有特殊含义的字符。

常用转义字符表

转义字符 名称 说明 示例
\t 制表符 水平制表，用于对齐 "北京\t天津\t上海"
\n 换行符 换到下一行开头 "第一行\n第二行"
\\ 反斜杠 表示一个反斜杠字符 "C:\\Windows\\System32"
\" 双引号 表示双引号字符 "他说：\"你好！\""
\' 单引号 表示单引号字符 '字符：\'A\''
\r 回车符 回到行首（覆盖） "abc\rde" → "dec"
\b 退格符 后退一格 "ab\bc" → "ac"
\f 换页符 换到下一页开头 用于打印机控制
* 案例：escape-character-example

常见问题与注意事项

  1. \r\n 与 \n\r
  2. \r\n：Windows系统的行结束符（回车+换行）
  3. \n\r：较少使用，先换行再回车

  4. \n：Unix/Linux/Mac系统的行结束符

  5. 八进制和十六进制转义

  6. 八进制：\ddd（d为0-7的数字），如\101表示'A'

  7. 十六进制：\xhh或\uhhhh，如\u0041表示'A'

  8. 文件路径问题：

  9. Windows路径："C:\\Users\\Name\\file.txt"

  10. 错误写法："C:\Users\Name\file.txt"（缺少转义）

  11. JSON字符串中的引号：

String json = "{\"name\":\"张三\",\"age\":25}";
  1. 正则表达式中的转义：
  2. 正则中的.需要转义为\\.
  3. Java中需要写为"\\."
