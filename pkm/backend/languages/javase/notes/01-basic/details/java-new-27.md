# Java27新特性

- JEP 527：TLS 1.3 的后量子混合密钥交换
- JEP 531：Lazy Constants (Third Preview)
- JEP 532：模式、instanceof 和 switch 中的原始类型 (Fifth Preview)
- JEP 533：结构化并发 (Seventh Preview)
- JEP 534：紧凑对象头默认启用
- JEP 536：JFR 进程内数据脱敏
- JEP 537：向量API (Twelfth Incubator)
- JEP 538：密码对象的 PEM 编码 (Third Preview)
