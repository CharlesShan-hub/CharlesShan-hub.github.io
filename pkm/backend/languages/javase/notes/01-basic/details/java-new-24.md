# Java24新特性

## 功能总览

2025年3月18日发布。非长期支持版本。

- JEP 488：模式、instanceof 和 switch 中的原始类型 (Second Preview)
- JEP 492：灵活的构造方法体 (Third Preview)
- JEP 494：模块导入声明 (Second Preview)
- JEP 495：简单源文件和实例main方法 (Fourth Preview)
- JEP 484：Class-File API（正式确定）
- JEP 485：Stream Gatherers（正式确定）
- JEP 499：结构化并发 (Fourth Preview)
- JEP 487：Scoped Values (Fourth Preview)
- JEP 489：向量API (Ninth Incubator)
- JEP 478：密钥派生函数API (Preview)
- JEP 496：抗量子密钥封装机制 ML-KEM（正式确定）
- JEP 497：抗量子数字签名算法 ML-DSA（正式确定）
- JEP 491：虚拟线程在 synchronized 中不再固定载体线程（正式确定）
- JEP 450：紧凑对象头 (Experimental)
- JEP 475：G1 延迟屏障展开
- JEP 404：分代 Shenandoah (Experimental)
- JEP 483：提前类加载与链接（AOT）
- JEP 472：准备限制 JNI 的使用
- JEP 486：永久禁用安全管理器
- JEP 498：使用 sun.misc.Unsafe 内存访问方法时发出警告
- JEP 490：ZGC：移除非分代模式
- JEP 479：移除 Windows 32位 x86 端口
- JEP 501：废弃 (Linux) 32位 x86 端口以备移除
- JEP 493：无需 JMOD 链接运行时镜像
