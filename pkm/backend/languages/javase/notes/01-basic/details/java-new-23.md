# Java23新特性

## 功能总览

2024年9月17日发布。非长期支持版本。

- JEP 455：模式、instanceof 和 switch 中的原始类型 (Preview)
- JEP 466：Class-File API (Second Preview)
- JEP 467：Markdown文档注释（正式确定）
- JEP 469：向量API (Eighth Incubator)
- JEP 473：Stream Gatherers (Second Preview)
- JEP 471：废弃 sun.misc.Unsafe 中的内存访问方法以备移除
- JEP 474：ZGC：默认启用分代模式（正式确定）
- JEP 476：模块导入声明 (Preview)
- JEP 477：隐式声明的类和实例main方法 (Third Preview)
- JEP 480：结构化并发 (Third Preview)
- JEP 481：Scoped Values (Third Preview)
- JEP 482：灵活的构造方法体 (Second Preview)
