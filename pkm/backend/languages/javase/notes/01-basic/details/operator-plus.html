1. 加号“+”在 Java 中是一种运算符，有两个作用：
    1. 求和：加号两边都是数字类型。
    2. 字符串拼接：两边任意一边是字符串类型，做字符串拼接操作，拼接之后的结果还是一个字符串。
  2. 判断以下程序的输出结果
System.out.println(5 + 6);
System.out.println("5" + "6");
System.out.println("5" + 6 + 7);
System.out.println("5" + (6 + 7));
System.out.println(5 + 6 + "7");
System.out.println(5 + "6" + 7);
System.out.println(5 + (6 + "7")); // 添加小括号优先级较高
