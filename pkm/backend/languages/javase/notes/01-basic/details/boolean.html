布尔类型

基本特性

  • 大小：占用1字节
  • 取值：只能是 true 或 false
  • 与C的区别：不能用0或非零整数代替 boolean
boolean isReady = true;
boolean isFinished = false;

// 错误：Java不支持数值到boolean的转换
// int flag = 1;
// boolean b = flag;

面试题：boolean占用多少字节

对于单独的boolean变量，理论上是1字节，但是JVM会对内存进行补齐，所以后边增加了三字节的空白。如果再加上对象头，一共占用了32 字节。
