# Java22新特性

## 功能总览

2024年3月19日发布。非长期支持版本。

- JEP 423：G1的区域固定（Region Pinning for G1）
- JEP 447：super(...)之前的语句 (Preview)
- JEP 454：外部函数与内存API（正式确定）
- JEP 456：未命名变量和模式（正式确定）
- JEP 457：Class-File API (Preview)
- JEP 458：启动多文件源码程序（正式确定）
- JEP 459：字符串模板 (Second Preview)
- JEP 460：向量API (Seventh Incubator)
- JEP 461：Stream Gatherers (Preview)
- JEP 462：结构化并发 (Second Preview)
- JEP 463：隐式声明的类和实例main方法 (Second Preview)
- JEP 464：Scoped Values (Second Preview)
