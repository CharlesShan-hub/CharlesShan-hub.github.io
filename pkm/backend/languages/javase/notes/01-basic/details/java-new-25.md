# Java25新特性

2025年9月16日发布。长期支持版本。

- JEP 470：密码对象的 PEM 编码 (Preview)
- JEP 502：Stable Values (Preview)
- JEP 503：移除 32位 x86 端口
- JEP 505：结构化并发 (Fifth Preview)
- JEP 506：Scoped Values（正式确定）
- JEP 507：模式、instanceof 和 switch 中的原始类型 (Third Preview)
- JEP 508：向量API (Tenth Incubator)
- JEP 509：JFR CPU时间分析 (Experimental)
- JEP 510：密钥派生函数API（正式确定）
- JEP 511：模块导入声明（正式确定）
- JEP 512：紧凑源文件和实例main方法（正式确定）
- JEP 513：灵活的构造方法体（正式确定）
- JEP 514：AOT 命令行易用性
- JEP 515：AOT 方法分析
- JEP 518：JFR 协作采样
- JEP 519：紧凑对象头（正式确定）
- JEP 520：JFR 方法计时与追踪
- JEP 521：分代 Shenandoah（正式确定）
