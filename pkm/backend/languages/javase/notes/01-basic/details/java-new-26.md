# Java26新特性

## 功能总览

2026年3月17日发布。非长期支持版本。

- JEP 500：准备让 final 真正意味着 final
- JEP 504：移除 Applet API
- JEP 516：任意 GC 下的 AOT 对象缓存
- JEP 517：HTTP Client API 支持 HTTP/3
- JEP 522：G1 GC：通过减少同步提升吞吐量
- JEP 524：密码对象的 PEM 编码 (Second Preview)
- JEP 525：结构化并发 (Sixth Preview)
- JEP 526：Lazy Constants (Second Preview)
- JEP 529：向量API (Eleventh Incubator)
- JEP 530：模式、instanceof 和 switch 中的原始类型 (Fourth Preview)
