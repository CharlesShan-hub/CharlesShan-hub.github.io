转换规则

  1. 默认转成最宽泛的类型；用常量赋值float需要指定f
int a = 1;
// 错误：1.1默认为double
float n1 = a + 1.1;

// 正确：明确指定float
float n2 = a + 1.1F;

// 正确：使用double接收
double n3 = a + 1.1;

// 正确：float+float没有自动变double
float f1 = 10.0f;
float f2 = 20.0f;
float f3 = f1 + f2;
  1. byte/short
// 语法糖：-128到127的int可以直接赋值给byte
// 正确：常量在范围内可自动转换
byte a = 127;
// 错误：超出范围
// byte b = 128;
// 正确：强制转换
byte c = (byte) 127;
// 正确：强制转换
byte c = (byte) 128;// 变成了-128了

System.out.println(Integer.toBinaryString(128));  
// 10000000
System.out.println(Integer.toBinaryString((byte)128));
// 11111111111111111111111110000000
// 因为byte强制转型，然后128本来的符号为0没了，数字位1变成了byte的符号了。

// 错误：变量无法判断范围
int temp = 97;
// byte d = temp;

// 正确：强制转换
byte e = (byte) temp;
  1. char与byte/short的特殊关系
// 正确：char可以直接保存整数常量
char f = 97;

// 错误：byte不能自动转成char
// char g = a;

// 正确：强制转换
char h = (char) a;
  1. byte/short运算会自动提升精度
byte age = 20;
byte age2 = 30;
// age + age2 的结果是int类型
int sum = age + age2;
  1. boolean不参与转换
boolean flag = true;
// 错误：boolean不能转换为其他类型
// int num = flag;

强制类型转换

通过类型转换运算符 (类型)：

double d = 3.14;
int i = (int) d;  // i = 3（截断小数部分）

基本类型与String的转换

基本类型 → String

int num = 123;
String s = num + "";  // "123"

String → 基本类型

使用WrapperClass的解析方法：

String s = "123";

int n1 = Integer.parseInt(s);
double n2 = Double.parseDouble(s);
float n3 = Float.parseFloat(s);
long n4 = Long.parseLong(s);
byte n5 = Byte.parseByte(s);
boolean n6 = Boolean.parseBoolean("true");
short n7 = Short.parseShort(s);

char → 基本类型

使用Character类（也是包装类）的方法：

int a = Character.getNumericValue('1');
int b = Character.digit('1', 10);

字符串操作

// 提取字符串中的字符
String s = "123";
char c = s.charAt(0);  // '1'

// 字符串相等比较（推荐方式）
String name = "林黛玉";
System.out.println("林黛玉".equals(name));  // 更好：避免空指针
System.out.println(name.equals("林黛玉"));   // 可能引发空指针异常

总结要点

  1. 变量命名：作用域内不能重名，Java不支持变量遮蔽
  2. 类型选择：
  3. 整数默认用 int，大数用 long
  4. 浮点数默认用 double，float 必须加 F 后缀
  5. 类型转换：
  6. 小范围类型可自动转大范围类型
  7. 大范围转小范围需要强制转换
  8. boolean 不参与类型转换
  9. 浮点数陷阱：避免直接比较，使用容差法
  10. 字符串操作：使用 equals() 比较字符串，注意空指针问题
  11. 字符特性：char 可参与数值运算，本质是Unicode编码
