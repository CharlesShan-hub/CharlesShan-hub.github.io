1. 编程题 Homework01.java

(1) 将字符串中指定部分进行反转。比如将"abcdef"反转为"aedcbf" (2) 编写方法 public static String reverse(String str, int start, int end) 搞定

package ex_chapter13;  

public class Ex01 {  
    public static void main(String[] args) {  
        String s = "01234567890";  
        System.out.println(s);  
        System.out.println(reverse1(s, 3,6));  
        System.out.println(reverse2(s, 3,6));  
    }  

    public static String reverse1(String str, int start, int end){  
        char[] chars = str.toCharArray();  
        char[] reversed = new char[end - start + 1];  
        for (int i = start, j = reversed.length-1; j>=0; i++, j--){  
            reversed[j] = chars[i];  
        }  
        for (int i = start, j = 0; j < reversed.length; i++, j++){  
            chars[i] = reversed[j];  
        }  
        return new String(chars);  
    }  

    public static String reverse2(String str, int start, int end){  
        if(str == null || str.isEmpty()) throw new IllegalArgumentException();  
        if(start < 0 || end > str.length() || start > end) throw new IllegalArgumentException();  

        char[] chars = str.toCharArray();  
        char temp;  
        for(int i = start, j = end; i<j; i++, j--){  
            temp = chars[i];  
            chars[i] = chars[j];  
            chars[j] = temp;  
        }  
        return new String(chars);  
    }  
}

2. 编程题 Homework02.java

输入用户名、密码、邮箱，如果信息录入正确，则提示注册成功，否则生成异常对象 要求： (1) 用户名长度为2或3或4 (2) 密码的长度为6，要求全是数字 (3) 邮箱中包含@和. 并且@在.的前面 isDigital

package ex_chapter13;  

import java.util.Scanner;  

public class Ex02 {  
    public static void main(String[] args) {  
        try{  
            String name = getName();  
            String code = getCode();  
            String mail = getMail();  
            System.out.println("成功注册");  
        }catch(Exception e){  
            System.out.println(e.getMessage());  
        }  
    }  

    public static String getName() throws NumberFormatException {  
        Scanner scanner = new Scanner(System.in);  
        System.out.print("请输入用户名:");  
        String name = scanner.nextLine();  
        if(name.length() > 4 || name.length() < 2)  
            throw new NumberFormatException();  
        return name;  
    }  

    public static String getCode() throws NumberFormatException {  
        Scanner scanner = new Scanner(System.in);  
        System.out.print("请输入密码(长度为 6):");  
        String code = scanner.nextLine();  
        if(code.length() != 6)  
            throw new NumberFormatException();  
        for(char c : code.toCharArray())  
            if(c<'0' || c>'9')  
                throw new NumberFormatException();  
        return code;  
    }  

    public static String getMail() throws NumberFormatException {  
        Scanner scanner = new Scanner(System.in);  
        System.out.print("请输入邮箱:");  
        String mail = scanner.nextLine();  
        if(!mail.contains("@") || !mail.contains("."))  
            throw new NumberFormatException();  
        if(mail.indexOf("@") > mail.lastIndexOf("."))  
            throw new NumberFormatException();  
        return mail;  
    }  
}

3. 编程题 Homework03.java

(1) 编写Java程序，输入形式为：Han Shun Ping的人名，以Ping,Han .S的形式打印出来 。其中.S是中间单词的首字母。 (2) 例如输入 “William Jefferson Clinton”，输出形式为：Clinton, William .J

package ex_chapter13;  

public class Ex03 {  
    public static void main(String[] args) {  
        String name = "Hong Tian Shan";  
        System.out.println(format(name));  
    }  

    public static String format(String name){  
        if(name == null) return null;  
        String[] items = name.split(" ");  
        if(items.length != 3)  
            throw new NumberFormatException();  
        return items[2]+","+items[0]+" ."+items[1].charAt(0);  
    }  
}
