排序

  • 简介：内部排序与外部排序

  • 冒泡排序：思路是通过n-1趟排序，每次把最大的放到本趟最后。

// 从小到大
int[] list = {1,3,5,2,4,6,10,13,17,16,15,11};
boolean flag = true;
int temp=0;
for(int i=0;i<list.length-1;i++){
  flag = true;
  for(int j=0;j<list.length-1-i;j++){
    if(list[j]>list[j+1]){
      temp = list[j];
      list[j] = list[j+1];
      list[j+1] = temp;
      flag = false;
    }
  }
  if(flag) break;
}
