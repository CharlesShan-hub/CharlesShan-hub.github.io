类与对象在内存中的存在形式

  1. 类和对象在内存中的形式

  2. 类的数据结构存储在方法区中

  3. 对象的引用存储在栈里，存储的是类的引用地址，指向堆
  4. 对象的数据存储在堆里。堆中数据的int直接存储。堆中的String的数据保存在方法区的常量池中，堆只保存指向常量池中某处的一个地址。

对象内存分配机制

观察下面代码：Person p1 = new Person();然后Person p2 = p1;

p1和p2都是对象的名字（对象引用），真正的内存空间是new Person()。Person p2 = p1;可以看成把p1赋给p2，也可以看成是把p2指向p1。

p1，p2其实是指向同一个内存空间。

class Person{
  int age;
}

Person p1 = new Person();
// 默认值
System.out.println(p1.age); // 0
// 赋值
Person p2 = p1;
System.out.println(p2.age); // 0
// 改变p1的age，p2会怎样？
p1.age = 100;
System.out.println(p2.age); // 100
// p2会和p1一起慢慢变老

例题：会输出什么？

Person a = new Person();
a.age = 10;
Person b = a;
b.age = 20;
b = null;
System.out.println(a.age);

这里b与a同是指向同一个地址。注意后来b指向了空，但不影响a指向原来的对象，所以输出20。

  int age;

  }
