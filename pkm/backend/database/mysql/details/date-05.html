date_add函数，date_sub函数

  • date_add函数的作用：给指定的日期添加间隔的时间，从而得到一个新的日期。
  • date_add函数的语法格式：date_add(日期, interval expr 单位)，例如：
  • 日期：一个日期类型的数据
    • interval：关键字，翻译为“间隔”，固定写法
    • expr：指定具体的间隔量，一般是一个数字。也可以为负数，如果为负数，效果和date_sub函数相同。
  • 单位
    • year：年
    • month：月
    • day：日
    • hour：时
    • minute：分
    • second：秒
    • microsecond：微秒（1秒等于1000毫秒，1毫秒等于1000微秒）
    • week：周
    • quarter：季度
  • 复合型单位
    • SECOND_MICROSECOND
    • MINUTE_MICROSECOND
    • MINUTE_SECOND：几分几秒之后
    • HOUR_MICROSECOND
    • HOUR_SECOND
    • HOUR_MINUTE：几小时几分之后
    • DAY_MICROSECOND
    • DAY_SECOND
    • DAY_MINUTE
    • DAY_HOUR：几天几小时之后
    • YEAR_MONTH：几年几个月之后
mysql> select now(), date_add(now(), interval 3 day);
+---------------------+---------------------------------+
| now()               | date_add(now(), interval 3 day) |
+---------------------+---------------------------------+
| 2026-02-21 15:09:47 | 2026-02-24 15:09:47             |
+---------------------+---------------------------------+
1 row in set (0.001 sec)

以'2023-01-03'为基准，间隔3天之后的日期：'2023-01-06'

mysql> select '2023-01-03', date_add('2023-01-03', interval 3 month);
+------------+------------------------------------------+
| 2023-01-03 | date_add('2023-01-03', interval 3 month) |
+------------+------------------------------------------+
| 2023-01-03 | 2023-04-03                               |
+------------+------------------------------------------+
1 row in set (0.002 sec)

这个是负数的情况

mysql> select '2023-01-03', date_add('2023-01-03', interval -3 month);
+------------+-------------------------------------------+
| 2023-01-03 | date_add('2023-01-03', interval -3 month) |
+------------+-------------------------------------------+
| 2023-01-03 | 2022-10-03                                |
+------------+-------------------------------------------+
1 row in set (0.001 sec)

以上SQL也可以采用date_sub函数完成，例如：

mysql> select '2023-01-03', date_sub('2023-01-03', interval 3 month);
+------------+------------------------------------------+
| 2023-01-03 | date_sub('2023-01-03', interval 3 month) |
+------------+------------------------------------------+
| 2023-01-03 | 2022-10-03                               |
+------------+------------------------------------------+
1 row in set (0.001 sec)

如果单位采用复合型的话，expr该怎么写呢？

dayofweek、dayofmonth、dayofyear函数

mysql> select
    -> now() 现在,
    -> dayofweek(now()) 一周,
    -> dayofmonth(now()) 一月,
    -> dayofyear(now()) 一年;
+---------------------+--------+--------+--------+
| 现在                | 一周   | 一月   | 一年   |
+---------------------+--------+--------+--------+
| 2026-02-21 15:39:56 |      7 |     21 |     52 |
+---------------------+--------+--------+--------+
1 row in set (0.000 sec)

dayofweek：一周中的第几天（1~7），周日是1，周六是7。 dayofmonth：一个月中的第几天（1~31） dayofyear：一年中的第几天（1~366）

last_day函数

获取给定日期所在月的最后一天的日期：

mysql> select last_day(now());
+-----------------+
| last_day(now()) |
+-----------------+
| 2026-02-28      |
+-----------------+
1 row in set (0.000 sec)

datediff函数

计算两个日期之间所差天数：（时分秒不算，只计算日期部分相差的天数）

mysql> select datediff('2019-10-01','1949-10-01');
+-------------------------------------+
| datediff('2019-10-01','1949-10-01') |
+-------------------------------------+
|                               25567 |
+-------------------------------------+
1 row in set (0.001 sec)

timediff函数

计算两个日期所差时间，例如日期1和日期2所差10:20:30，表示差10小时20分钟30秒。

mysql> select timediff(now(),'2000-1-1 0:0:0');
+----------------------------------+
| timediff(now(),'2000-1-1 0:0:0') |
+----------------------------------+
| 838:59:59                        |
+----------------------------------+
1 row in set, 1 warning (0.001 sec)
