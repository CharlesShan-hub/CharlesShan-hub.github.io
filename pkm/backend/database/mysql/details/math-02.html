round(x)和round(x,y)四舍五入

  • round(x) 四舍五入，保留整数位，舍去所有小数
  • round(x,y) 四舍五入，保留y位小数
mysql> select round(3.1415);
+---------------+
| round(3.1415) |
+---------------+
|             3 |
+---------------+
1 row in set (0.001 sec)

mysql> select round(3.1415,2);
+-----------------+
| round(3.1415,2) |
+-----------------+
|            3.14 |
+-----------------+
1 row in set (0.000 sec)

mysql> select round(31.415,-1);
+------------------+
| round(31.415,-1) |
+------------------+
|               30 |
+------------------+
1 row in set (0.001 sec)

ceil与floor

数字处理函数除了以上的之外，还有ceil和floor函数：

  • ceil函数：返回大于或等于数值x的最小整数
  • floor函数：返回小于或等于数值x的最大整数
mysql> select ceil(1.1), floor(1.1);
+-----------+------------+
| ceil(1.1) | floor(1.1) |
+-----------+------------+
|         2 |          1 |
+-----------+------------+
1 row in set (0.000 sec)

mysql> select ceil(-1.1), floor(-1.1);
+------------+-------------+
| ceil(-1.1) | floor(-1.1) |
+------------+-------------+
|         -1 |          -2 |
+------------+-------------+
1 row in set (0.001 sec)
