case

上面这个需求也可以使用：case.. when.. then.. when.. then.. else.. end来完成：

select ename, job,
case job
when 'MANAGER' then sal*1.1
when 'SALESMAN' then sal*1.2
else sal
end as sal
from emp;

mysql> select ename, job,
    -> case job
    -> when 'MANAGER' then sal*1.1
    -> when 'SALESMAN' then sal*1.2
    -> else sal
    -> end as sal
    -> from emp;
