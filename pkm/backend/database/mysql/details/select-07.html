案例：找出薪资大于3000的员工姓名、薪资

mysql> select 
    -> ename, sal
    -> from
    -> emp
    -> where
    -> sal > 3000;
+-------+---------+
| ename | sal     |
+-------+---------+
| KING  | 5000.00 |
+-------+---------+
1 row in set (0.001 sec)
