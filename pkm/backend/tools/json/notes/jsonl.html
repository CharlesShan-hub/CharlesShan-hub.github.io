Notes

  1. jsonl syntax[2]
  2. JSONL是一种基于文本的格式，使用.jsonl文件扩展名，基本上与JSON格式相同，但使用换行符来分隔JSON值。也称为_JSON Lines_。
  3. jsonl 每一行是一个 json，一次解析一行，每一行不超过 2G，这对于在内存有限的机器上处理非常大的文件非常有用。
  4. JSON vs JSONL[2]
  5. JSONL使用UTF-8编码。这与JSON不同，JSON允许使用ASCII转义序列编码Unicode字符串。
  6. 每一行都是有效的JSON值。
  7. 每一行都用一个换行符"\n“分隔。这意味着还支持回车、换行符序列“\r\n”，因为在解析JSON值时会隐式忽略周围的白色空格。文件中的最后一个字符可能是行分隔符，它将被视为没有行分隔符。
  8. JSONL 有时比 CSV 更好，因为CSV 损坏了很难处理。
