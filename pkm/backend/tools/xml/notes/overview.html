XML 概述

XML（eXtensible Markup Language，可扩展标记语言）是一种用于存储和传输数据的标记语言（相比而言HTML是展示数据的，而不是存储的），由万维网联盟（W3C）于1998年推出。

基本概念

  1. 标记语言：XML使用标签来描述数据结构
  2. 可扩展性：用户可以自定义标签
  3. 平台无关：独立于硬件和软件
  4. 纯文本格式：人类可读且机器可解析

主要特点

  • 结构化数据表示：以层次结构组织数据
  • 自描述性：标签名称通常描述其内容
  • 语法严格：要求良好格式
  • 广泛支持：几乎所有编程语言都提供XML处理工具

基本语法规则

<?xml version="1.0" encoding="UTF-8"?>
<rootElement>
  <childElement attribute="value">
    Content text
  </childElement>
  <emptyElement/>
</rootElement>
  1. 必须有且只有一个根元素
  2. 标签区分大小写
  3. 所有标签必须闭合
  4. 属性值必须加引号
  5. 特殊字符需转义（如&lt;代表<）

可以让浏览器打开某个xml文件，如果能正常打开就说没有语法错误。

关于 XML 声明

以下是一个完整的声明：

<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
属性​ 说明​ 是否可选​
version​ 指定 XML 版本（通常是 1.0​ 或 1.1） 必选​
encoding​ 指定文档字符编码（如 UTF-8、GBK） 可选（默认取决于解析器）
standalone​ 定义文档是否依赖外部 DTD（yes/no） 可选，默认值 no，yes 的时候表示本 XML 不依赖任何外部 DTD 约束，即它的结构和约束完全由自身定义。

注意事项：

  • 必须放在第一行，前面不能有任何字符（包括空格）。
  • 大小写敏感
  • ✅ 正确写法：<?xml version="1.0" encoding="UTF-8"?>
  • ❌ 错误写法：<?XML ...?>或 <?Xml ...?>或 <?xMl ...?>
  • version="1.0" 是最常用的，version="1.1" 版本较少使用。
  • encoding​ 推荐使用 UTF-8，避免乱码问题。

XML应用领域

  • 数据存储（相当于小型数据库）
  • 数据交换（不同语言或不同系统之间交换数据的通用格式）
  • 配置文件（如 JavaWeb 项目中的 web.xml 配置文件）
  • 用作协议（如 SOAP 协议）（SOAP（Simple Object Access Protocol，简单对象访问协议）是一种基于 XML​ 的、用于在网络中交换结构化信息的协议规范。它主要用于 Web 服务（Web Services）之间的通信，是实现 W3C Web 服务架构的核心协议之一。）
