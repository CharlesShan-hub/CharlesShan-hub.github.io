这些是智能电表的电能累计值，记录的是一段时间内的总量（而不是瞬时值）。我用水表的概念类比，你就完全明白了：

核心区别：功率 vs 电能

  • MMXU​ 测量的是功率（瞬时值，此刻的流速）

    → 就像水龙头的当前流速（升/秒）

  • MMTR​ 记录的是电能（累计值，一段时间内的总量）

    → 就像水表的总用水量（立方米）

一、两类电能：正向 vs 反向

1. 正向电能（从电网取电）

字段 含义 水表类比 谁付钱
TotWh​ 正向总有功电能 从自来水公司买的总水量 用户付钱给电网
TotVArh​ 正向总无功电能 辅助用水量 电网可能考核或罚款​

→ 普通家庭用电，只会有这两个值增加

2. 反向电能（向电网送电）

字段 含义 水表类比 谁付钱
SupWh​ 供电有功电能 你卖给别人的水量 电网付钱给你
SupVArh​ 供电无功电能 辅助送出量 通常不计费

→ 装了光伏发电的用户，白天发电用不完，卖给电网

二、关键概念：需量（Dmd）

需量 = 短时间内的最大功率需求

字段 含义 通俗解释
DmdWh​ 需量有功电能 15分钟内最大的平均有功功率​
DmdVArh​ 需量无功电能 15分钟内最大的平均无功功率​

为什么要记录需量？

工业电费 = 电度电费 + 基本电费

  • 电度电费：按TotWh（用了多少度电）

  • 基本电费：按DmdWh（你最大需求是多少）

例子：工厂用电

一个月用电：
- TotWh = 100,000 kWh    ← 用了10万度电
- DmdWh = 800 kW         ← 某15分钟内平均功率达800kW

电费计算：
1. 电度电费：100,000 kWh × 1元/kWh = 100,000元
2. 基本电费：800 kW × 40元/kW·月 = 32,000元
3. 总电费：132,000元

→ 即使你后来用电少了，也要按最高需求交容量费

三、完整场景举例

用户：装了光伏的工厂

一天的数据：
- 正向总有功电能 TotWh = 5,000 kWh
  （夜里生产，从电网买电）
- 供电有功电能 SupWh = 800 kWh  
  （白天发电太多，卖给电网）
- 需量有功电能 DmdWh = 600 kW
  （下午2点-2点15分用电最猛）

实际结算：
从电网净取电 = 5,000 - 800 = 4,200 kWh
基本电费按600kW计算

电网角度：

  • TotWh​ → 卖给用户的电

  • SupWh​ → 用户返售的电

  • DmdWh​ → 规划电网容量依据

四、单位说明

缩写 中文 含义
Wh 瓦时 1瓦用1小时 = 1瓦时
kWh 千瓦时 1度电 = 1千瓦时
VArh 乏时 无功电能单位

换算：1 kWh = 1,000 Wh = 1度电

五、实际电费单对应

居民电费单：
- 电量：XXX kWh         ← 对应 TotWh
- 金额：XXX 元

工业电费单：
- 电度电费：XXX 元      ← 对应 (TotWh - SupWh)
- 基本电费：XXX 元      ← 对应 DmdWh
- 力调电费：XXX 元      ← 对应 无功考核(TotVArh)
- 总计：XXX 元

简单总结：

  • TotWh​ → 你用了电网多少电（花钱）

  • SupWh​ → 你卖给电网多少电（赚钱）

  • DmdWh​ → 你最大需求是多少（决定容量费）

就像你家的水表，既要看总用水量，也要看最高用水时段（决定水压是否够用）！
