这些是电力系统中最核心的三相电气测量量，是电力监控的基础。我来用最易懂的方式解释：

一、先看“总和”类（最重要）

缩写 全称 通俗解释 单位
TotW​ Total Watt (总有功功率) 实际做功的功率
→ 电器真正用的“劲”
→ 电费主要按这个收		 千瓦(kW)
TotVAr​ Total Volt-ampere reactive (总无功功率) 建立磁场的“辅助功率”
→ 不做功但必须存在
→ 影响电网效率		 千乏(kVAr)
TotVA​ Total Volt-ampere (总视在功率) “看起来的”总功率
→ 有功+无功的综合
→ 决定变压器容量		 千伏安(kVA)

关系（功率三角形）：

      /|
     / |
 VA /  | VAr   ← 视在功率是斜边
   /   |
  /____|
    W        ← 有功功率是底边

公式：VA² = W² + VAr²

缩写 全称 通俗解释
TotPF​ Total Power Factor (总功率因数) 用电效率指标
→ 范围：0~1（1最好）
→ PF = W ÷ VA
→ 工厂要补偿到0.9以上
Hz​ Frequency (频率) 电网心跳
→ 中国：50Hz（1秒50次）
→ 质量指标，必须稳定

二、再看“分相”类（A/B/C三相）

前缀 含义 举例
PPV​ Phase-Phase Voltage (线电压) AB、BC、CA之间的电压
→ 380V（工业用）
PhV​ Phase Voltage (相电压) A、B、C对中性点的电压
→ 220V（家庭用）
A​ Current (电流) 每相的电流值
W​ Watt per phase (分相有功) 每相的有功功率
VAr​ VAr per phase (分相无功) 每相的无功功率
VA​ VA per phase (分相视在) 每相的视在功率
PF​ Power Factor per phase (分相功率因数) 每相的功率因数

三、实际例子（一看就懂）

场景：一个工厂的三相用电

测量值：
- TotW = 500 kW      ← 这个月要付电费的主要部分
- TotVAr = 300 kVAr   ← 无功太大，要装电容补偿
- TotVA = 583 kVA     ← 变压器容量至少需630kVA
- TotPF = 0.86       ← 有点低，最好补偿到0.9以上
- Hz = 50.02 Hz      ← 正常，在49.8~50.2之间都行

分相不平衡故障：

A相：W = 200 kW,  A = 300A
B相：W = 150 kW,  A = 280A  ← 电流偏大！
C相：W = 150 kW,  A = 220A

→ B相电流异常，可能缺相或负载不平衡

四、测量单位说明

符号 含义 倍数关系
k 千 1,000倍
M 兆 1,000,000倍
例：
1000 kW = 1 MW
0.5 kA = 500 A

五、为什么需要这些测量？

  1. 计费：TotW→ 算电费
  2. 设备选型：TotVA→ 选变压器容量
  3. 电能质量：Hz, PF→ 评估电网健康
  4. 故障诊断：分相值 → 定位问题
  5. 无功补偿：TotVAr→ 决定电容投切

简单记：

  • W​ → “干活”的功率（电费）
  • VAr​ → “不干活”的功率（辅助）
  • VA​ → “看起来”的功率（容量）
  • PF​ → 干活效率（越高越好）
  • Hz​ → 电网心跳（必须50Hz）

这些都是电力系统的“健康指标”，就像人体的血压、心率一样！
