asn1c + PER 编解码完整上手指南

工具：asn1c v0.9.21 · 编译器：MSYS2 ucrt64 GCC · 平台：Windows
场景：用 ASN.1 定义电力设备状态上报报文，生成 C 代码，完成 UPER 编码 → 解码 → 验证全流程。

1. 前置条件

软件 路径 说明
asn1c D:\program\asn1c\ 含 bin\asn1c.exe 和 skeletons\
GCC (ucrt64) D:\program\msys64\ucrt64\bin\gcc.exe MSYS2 UCRT64 工具链

2. ASN.1 定义文件

文件名：first.asn1

-- simple-mms.asn1
SimpleMMS DEFINITIONS ::= BEGIN

MMSpdu ::= SEQUENCE {
    invokeID    INTEGER,
    timestamp   OCTET STRING (SIZE(8)),
    service     ServiceRequest
}

ServiceRequest ::= CHOICE {
    read    [0] IMPLICIT ReadRequest
}

ReadRequest ::= SEQUENCE {
    variableName    VisibleString
}

END

注意 * 直接使用了 timestamp OCTET STRING (SIZE(8)) 而不是 UTCTime 或者UtcTime * 直接使用了 invokeID INTEGER 而不是 invokeID INTEGER(0..4294967295)

3. 生成 C 代码

文件名：generate.sh

#!/bin/bash
# generate.sh - Simple .lnk fix

PROJECT_ROOT="/d/project/playground/learn-asn1c/first"
ASN1C_ROOT="/d/program/asn1c"
WORK_DIR="$PROJECT_ROOT/scripts"
OUT_DIR="$PROJECT_ROOT/cproj/lib"
ASN1C_PATH="$ASN1C_ROOT/asn1c.exe"
SKELETON_DIR="$ASN1C_ROOT/skeletons"
ASN1_FILE="$PROJECT_ROOT/asn1/first.asn1"

echo "Generating ASN.1 code"

# Clear output
if [ -d "$OUT_DIR" ]; then
    echo "Cleaning output directory"
    rm -rf "$OUT_DIR"/*
else
    mkdir -p "$OUT_DIR"
fi

cd "$OUT_DIR"

# Run asn1c
echo "Running asn1c..."
"$ASN1C_PATH" -gen-PER -pdu=auto -S "$SKELETON_DIR" "$ASN1_FILE" >/dev/null 2>&1

echo "=== Files generated by asn1c ==="
# Show only a summary
echo "Total files: $(ls -1 | wc -l)"
echo "Symlinks: $(ls -l | grep " -> " | wc -l)"
echo "Regular files: $(ls -l | grep -v " -> " | tail -n +2 | wc -l)"
echo ""

# Simple fix: if file in B exists in A, remove it from B
echo "=== Removing files that exist in skeleton ==="
removedFiles=()

for file in *; do
    if [ -f "$file" ]; then
        baseName="$file"
        # Remove .lnk extension if present
        if [[ "$file" == *.lnk ]]; then
            baseName="${file%.lnk}"
        fi

        # Check if file exists in skeleton
        if [ -f "$SKELETON_DIR/$baseName" ]; then
            echo "Removing: $file (exists in skeleton as $baseName)" >/dev/null
            rm -f "$file"
            # Add to list for copying
            removedFiles+=("$baseName")
        fi
    fi
done
echo "Removed ${#removedFiles[@]} files"

echo ""
echo "=== Copying files from skeleton ==="
# Copy files that were removed
for file in "${removedFiles[@]}"; do
    if [ -f "$SKELETON_DIR/$file" ]; then
        echo "Copying: $file from skeleton" >/dev/null
        cp -f "$SKELETON_DIR/$file" .
    fi
done
echo "Copied ${#removedFiles[@]} files"

# Remove converter-sample.c if it exists
if [ -f "converter-sample.c" ]; then
    echo "Removing converter-sample.c"
    rm -f converter-sample.c
fi

echo ""
echo "=== Final files ==="
echo "Total files: $(ls -1 | wc -l)"
cFiles=$(find . -name "*.c" -type f | wc -l)
hFiles=$(find . -name "*.h" -type f | wc -l)
echo "Total: $cFiles .c files, $hFiles .h files"

cd "$WORK_DIR"

脚本功能：

  • 清理目录：清空 cproj/lib/中旧文件
  • 生成代码：使用 asn1c 编译器从 ASN.1 生成 C 代码
  • 修复符号链接：处理 Windows 创建的 .lnk 文件，用真实文件替换
  • 复制运行时库：从骨架目录复制所有必需文件
  • 清理示例：移除不需要的示例文件
  • 输出统计：显示生成的文件数量

关键参数：

  • -gen-PER：生成 PER 编解码支持
  • -pdu=auto：自动识别协议数据单元
  • -S <path>：指定骨架文件目录

4. 测试c代码

文件名：test.c

// test.c - Fixed version
#include <stdio.h>
#include <stdlib.h>
#include "../lib/MMSpdu.h"
#include "../lib/INTEGER.h"

int main() {
    printf("=== Simple ASN.1 Test ===\n\n");

    // Use heap allocation to avoid ASN_STRUCT_FREE crash
    MMSpdu_t *pdu = calloc(1, sizeof(MMSpdu_t));
    if (!pdu) {
        printf("ERROR: Memory allocation failed\n");
        return 1;
    }

    // Set invokeID
    asn_long2INTEGER(&pdu->invokeID, 12345);

    // Read back invokeID
    long val = 0;
    asn_INTEGER2long(&pdu->invokeID, &val);
    printf("invokeID: %ld\n", val);

    // Set timestamp
    const uint8_t timestamp[8] = {0x20, 0x24, 0x01, 0x15, 0x10, 0x30, 0x45, 0x00};
    OCTET_STRING_fromBuf(&pdu->timestamp, (const char*)timestamp, 8);
    printf("timestamp: %d bytes\n", (int)pdu->timestamp.size);

    // Set service
    pdu->service.present = ServiceRequest_PR_read;
    OCTET_STRING_fromBuf(&pdu->service.choice.read.variableName, "Test", 4);
    printf("variable: %d bytes\n", (int)pdu->service.choice.read.variableName.size);

    // Cleanup - this works with heap allocation
    ASN_STRUCT_FREE(asn_DEF_MMSpdu, pdu);

    printf("\n=== PASS ===\n");
    return 0;
}

关键点：

1. 堆分配：必须使用 calloc() 分配结构，ASN_STRUCT_FREE 不能释放栈变量 2. INTEGER 操作：asn_long2INTEGER() 设置值，asn_INTEGER2long() 读取值 3. OCTET_STRING 操作：OCTET_STRING_fromBuf() 从字节数组初始化 4. CHOICE 操作：设置 present 字段选择类型，访问对应的 choice 成员 5. 内存管理：ASN_STRUCT_FREE() 释放 ASN.1 结构及其嵌套内容

文件名：testc.sh

#!/bin/bash
# testc.sh - Compile and run MMS ASN.1 test program

# Define path variables
PROJECT_ROOT="/d/project/playground/learn-asn1c/first"
GCC="gcc"

# Source directories
SRC_DIR="$PROJECT_ROOT/cproj/src"
LIB_DIR="$PROJECT_ROOT/cproj/lib"
OUT_DIR="$PROJECT_ROOT/cproj/out"

# Input files
TEST_SRC="$SRC_DIR/test.c"
OUT_EXE="$OUT_DIR/mms-test.exe"

# Parameter parsing
SHOW_COMMAND_ONLY=0
CLEAN=0
for arg in "$@"; do
    case "$arg" in
        -c|--clean) CLEAN=1 ;;
        -s|--show|--show-command) SHOW_COMMAND_ONLY=1 ;;
        -h|--help)
            echo "Usage: $0 [options]"
            echo "Options:"
            echo "  -c, --clean         Clean output directory"
            echo "  -s, --show-command  Show compile command only"
            echo "  -h, --help          Show this help"
            exit 0
            ;;
    esac
done

echo "=== MMS ASN.1 Test Script ==="
echo "Project: $PROJECT_ROOT"
echo ""

# Clean if requested
if [ $CLEAN -eq 1 ]; then
    echo "Cleaning output directory..."
    if [ -d "$OUT_DIR" ]; then
        rm -rf "$OUT_DIR"/*
        echo "Cleaned: $OUT_DIR"
    fi
    exit 0
fi

# Check test file exists
if [ ! -f "$TEST_SRC" ]; then
    echo "Error: Test file not found: $TEST_SRC"
    exit 1
fi

# Get library files
libFiles=()
while IFS= read -r file; do
    if [ "$(basename "$file")" != "converter-sample.c" ]; then
        libFiles+=("$file")
    fi
done < <(find "$LIB_DIR" -name "*.c" -type f)

if [ ${#libFiles[@]} -eq 0 ]; then
    echo "Error: No ASN.1 generated files found. Run generate.sh first."
    exit 1
fi

# Build compile command
compileCmd="$GCC -I \"$LIB_DIR\" -I \"$SRC_DIR\" -g -O0 -Wall -Wextra -Wno-unused-parameter -Wno-unused-variable -lws2_32 \"$TEST_SRC\""

for file in "${libFiles[@]}"; do
    compileCmd="$compileCmd \"$file\""
done

compileCmd="$compileCmd -o \"$OUT_EXE\""

# Show command only mode
if [ $SHOW_COMMAND_ONLY -eq 1 ]; then
    echo "Compile command (${#compileCmd} chars):"
    echo "$compileCmd"
    exit 0
fi

# Normal mode: compile and run
echo "Compiling $((${#libFiles[@]} + 1)) files..."

# Create output directory
mkdir -p "$OUT_DIR"

# Compile
echo "Compiling..."
eval $compileCmd
exitCode=$?

if [ $exitCode -ne 0 ]; then
    echo "Error: Compilation failed with code: $exitCode"
    echo "Try running:"
    echo "$compileCmd"
    exit 1
fi

echo "Compilation successful: $OUT_EXE"

# Run the test
echo ""
echo "Running test program..."
echo "------------------------------------------------------------"

"$OUT_EXE"
exitCode=$?

echo "------------------------------------------------------------"
echo "Exit code: $exitCode"
echo "Test completed"

exit $exitCode
