    • BFS、DFS

    • 最小生成树

    • 关键路径
    • 拓扑排序

  • 顺序查找和折半查找
    • 顺序查找、折半查找、分块查找

    • 二叉排序树(BST)：概念、删除结点、ASL
    • 平衡二叉树(AVL)：平衡因子、插入(LL LR RL RR)
    • 红黑树
  • B树和B+树
    • B树（非叶最少floor{m/2}子结点）、B+树
  • 散列表
    • 线性探测法，计算ASL(成功、失败)

    • 最少比较次数上取整{log2 n!}，稳定性

    • 冒泡排序、快速排序
  • 选择排序
    • 简单选择排序、堆排序

    • 内部排序算法比较与应用

    • 多路平衡归并与败者树、置换选择排序、最佳归并树
