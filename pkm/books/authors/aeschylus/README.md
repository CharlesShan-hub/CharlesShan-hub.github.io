# 埃斯库罗斯

> - 原名：Aeschylus
> - 生卒：前525–前456
> - 国籍/朝代：古希腊·古典时期
> - 体裁/流派：戏剧、悲剧
> - 书目数：7

## 简介

埃斯库罗斯（约前525—前456）是古希腊悲剧诗人，被后人尊为"悲剧之父"。他参加过马拉松战役，增设了第二位演员，使严格意义上的戏剧对话成为可能。一生约写80—90出悲剧、13次获胜，传世仅7出，其中《俄瑞斯忒亚》是流传至今的唯一完整的古希腊三连剧。他的悲剧气势磅礴，深化了命运主题，代表作还有《被缚的普罗米修斯》。
