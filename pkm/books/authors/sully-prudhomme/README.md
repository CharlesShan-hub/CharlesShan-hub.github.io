# 苏利·普吕多姆

> - 书目数：1

## 简介


> Wiki: https://zh.wikipedia.org/wiki/%E8%8B%8F%E5%88%A9%C2%B7%E6%99%AE%E5%90%95%E5%A4%9A%E5%A7%86



**勒内-弗朗索瓦-阿尔芒·“苏利”·普吕多姆**（法语：René-François-Armand "Sully" Prudhomme，法语发音：[[syli pʁydɔm]](https://zh.wikipedia.org/wiki/Help:%E6%B3%95%E8%AA%9E%E5%9C%8B%E9%9A%9B%E9%9F%B3%E6%A8%99 "Help:法语国际音标")；1839年3月16日—1907年9月6日），[法国](https://zh.wikipedia.org/wiki/%E6%B3%95%E5%9B%BD "法国")[诗人](https://zh.wikipedia.org/wiki/%E8%AF%97%E4%BA%BA "诗人")，首位[诺贝尔文学奖](https://zh.wikipedia.org/wiki/%E8%AF%BA%E8%B4%9D%E5%B0%94%E6%96%87%E5%AD%A6%E5%A5%96 "诺贝尔文学奖")得主。

普吕多姆早年学习理科，后转向[文学](https://zh.wikipedia.org/wiki/%E6%96%87%E5%AD%A6 "文学")。其出道作是一八六五年他自费印的诗集《节日与诗》。从诗集中“生活”、“女性”、“青年”和“其他”各部分标题，人们就可想见普鲁多姆诗歌的主题：对生活、理想、爱情、青春的追求和对故乡、祖国、人民的挚爱，其中一些诗作也流露出作者对社会现实的不满和忧虑。<sup>[[1]](https://zh.wikipedia.org/wiki/%E8%8B%8F%E5%88%A9%C2%B7%E6%99%AE%E5%90%95%E5%A4%9A%E5%A7%86#cite_note-name-1)</sup> 出道作的出版使普鲁多姆在国内一举成名，于是他干脆辞去律师职务，专事写作，成为十九世纪后期法国有影响的诗人之一。先后出版抒情诗集《孤独》、《徒然的柔情》和哲理诗集《命运》、《正义》、《幸福》。前者以细腻含蓄的笔触、典雅精致的形式咏物状景，抒发个人不无伤感的情怀。<sup>[[1]](https://zh.wikipedia.org/wiki/%E8%8B%8F%E5%88%A9%C2%B7%E6%99%AE%E5%90%95%E5%A4%9A%E5%A7%86#cite_note-name-1)</sup>哲理诗则致力探索人类意识与现代社会的矛盾，寻求正义与幸福的内涵。在哲理诗中，普鲁多姆贯注了[科学进化论](https://zh.wikipedia.org/w/index.php?title=%E7%A7%91%E5%AD%B8%E9%80%B2%E5%8C%96%E8%AB%96&action=edit&redlink=1 "科学进化论（页面不存在）")内容，体现了对高尚道德的追求。<sup>[[1]](https://zh.wikipedia.org/wiki/%E8%8B%8F%E5%88%A9%C2%B7%E6%99%AE%E5%90%95%E5%A4%9A%E5%A7%86#cite_note-name-1)</sup>

由于普鲁多姆的诗歌创作和多方面文学成就，1881年他成为[法兰西学术院](https://zh.wikipedia.org/wiki/%E6%B3%95%E5%85%B0%E8%A5%BF%E5%AD%A6%E6%9C%AF%E9%99%A2 "法兰西学术院")院士<sup>[[1]](https://zh.wikipedia.org/wiki/%E8%8B%8F%E5%88%A9%C2%B7%E6%99%AE%E5%90%95%E5%A4%9A%E5%A7%86#cite_note-name-1)</sup>。1901年，他荣获首届[诺贝尔文学奖](https://zh.wikipedia.org/wiki/%E8%AF%BA%E8%B4%9D%E5%B0%94%E6%96%87%E5%AD%A6%E5%A5%96 "诺贝尔文学奖")。
