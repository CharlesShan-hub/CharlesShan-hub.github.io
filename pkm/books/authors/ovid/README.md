# 奥维修

> - 原名：Ovid
> - 生卒：前43–约17
> - 国籍/朝代：古罗马·帝国时期
> - 体裁/流派：诗歌、史诗
> - 分类：B
> - 书目数：1

## 简介

奥维德（前43—18）是罗马黄金时期的诗人，或许是罗马历史上最擅长编写故事的诗人。他有奇妙的想象力，在六音步史诗型作品《变形记》里，用流行于西方和近东地区的神话及趣闻编写光怪陆离的故事；还写过悲剧、爱情诗和"书信"等。薄伽丘和乔叟等后世文人均曾广泛得益于他的创作。
