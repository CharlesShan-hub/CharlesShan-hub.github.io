# 苏菲·汉娜

> - 书目数：1

## 简介

苏菲·汉娜（Sophie Hannah，1971— ），英国诗人、推理小说家。经阿加莎·克里斯蒂遗产协会官方授权，续写赫尔克里·波洛探案，2014 年出版《字母袖扣谋杀案》（The Monogram Murders），此后又有系列续作。新星出版社将《字母袖扣谋杀案》编入午夜文库「全85册」全集，作为第 85 册。
