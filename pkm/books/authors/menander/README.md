# 米南德

> - 原名：Menander
> - 生卒：约前342–前291
> - 国籍/朝代：古希腊·希腊化时期
> - 体裁/流派：戏剧、喜剧
> - 书目数：1

## 简介

米南德（约前342—前292）是"希腊化"时期新喜剧的代表作家，据说写过百余部喜剧，传世的有《恨世者》《萨摩斯女子》及一些残篇。剧作多以日常生活为题材，结构紧凑，性格鲜明，语言接近口语，对罗马喜剧家影响很大，并通过他们影响后世欧洲喜剧。
