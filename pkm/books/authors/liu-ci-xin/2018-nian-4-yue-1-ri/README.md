# 2018年4月1日

## 阅读感受 - 2026-10-24

> 会有剧透～

对一下五点重新进行个人的理解表述：

1. ✅精神内核：仍然是刘慈欣常说的“虚拟与现实”对抗的母题，不过也加入了生物技术的畅想，内容更加丰富。
2. ❌语言表达：个人认为语言和其它大师的作品相差甚远，不过瑕不掩瑜，但作为单独维度的评价，还是叉叉。
3. ✅时代意义：仍然是刘慈欣常说的，对于现实过于重视网络技术的反思。
4. ❌社会名气：不是很有名。
5. ❌重读意愿：比较单调。

## 阅读感受 - 2026-10-22

> 这个是一个虚构作品，下面的感受会对情节进行剧透。

《2018年4月1日》是一个很短很短的作品，最初于2009年发表。为了更好的带入当时的社会，下面是一个时间线。

* 1938：美国遗传学家 赫尔曼·穆勒（Hermann Muller）和 巴巴拉·麦克林托克（Barbara McClintock）各自在研究染色体时发现了这个特殊的末端结构。
* 2003：支付宝成立，美团成立
* 2009（这里）：大刘写了《2018年4月1日》
* 2013：余额宝带火支付宝，同年八月微信推出微信支付
* 2014：二维码和补贴大战，快的/滴滴打车平台大战，ofo在校园中成立
* 2015：美团和大众点评合并，成立美团点评
* 2017：《Attention is All You Need》被发表
* 2018：OpenAI发布第一版GPT模型

当时刚好是互联网发展最快并且格局上未打开的时代。移动支付等概念都出现了，难怪大刘能想到所谓的互联网共和国。里面很多的内容都很有趣，比如互联网共和国的军队这个我感觉是最幽默的了。还有里面说互联网成立实体和现实国家对立这个就有点理想了，事实上现实更残酷，互联网共和国只有在真正开放的地方才能实现，但是现实中互联网是困于每一个大公司，大公司之间做信息茧房，做内容护城河，其实根本没有自发的成立共同体的空间。

另一个书中说的，程序员只需要改一下数据库就可以把国家的钱弄没，这就是数据安全的问题，后边为了解决这个问题，也有了区块链加密货币等概念，但事实上这个方法并不成功，因为挖矿本身是需要高仿代价的，就需要一定的补偿也就是加密货币本身，随着挖矿本身的难度增加，越来越多人会聚合在一起成为挖矿的集体，结果这个集体反而又成了一种自发的中心化。

可以看到书中语言的计算机和信息行业的发展大致准确，但是生物医疗确很遥远，我们已经知道了基因上瑞粒就是影响衰老的因素，但是这个1938年的发现直到2026年仍然还是理论阶段，大刘说的那种基于基因的医疗，现在还没有实现。

这本书实在太短了，感觉刚开始一个头，就结束了。开头描写了一些技术背景和人物关系，但是很多人都没有展开呢。我想如果让今天的我来写，我可能先从一段景物描写开始，然后慢慢引入时代背景。比如描写2009想象的2018年的未来，街头巷尾的场景，电视或者新闻播放的画面。人们的行色匆匆，表情，行程，最后其中有一个人是男主人公。在引入男主的所思所想。里面还可以用一些回忆的方式铺垫一下女友。里面有很多冲突都没来及展开，如果展开写确实可以作为一个大长篇的。

如果说对于我有什么收获呢，可能就是，我之前认为我自己总对未来有着很强的直觉，现在看来这个直觉其实是非常普遍的，比如这本书就是一个例子。另外直觉本身其实也是投资和科研的方向，从而进一步引导社会走向直觉中的世界。

## 主要内容

> AI总结版本

《2018年4月1日》是刘慈欣的一篇短篇小说，背景设定在2018年。此时人类社会已有三项关键技术：基延（基因改造延长寿命至三百岁，价格昂贵，只有富人用得起）、冬眠（低温休眠，睡一百年生理年龄只长一岁，相对便宜）、以及互联网上形成的虚拟国家（如由IT工程师组成的“IT共和国”，拥有与实体国家抗衡的力量）。

主角“我”是个底层财务人员，策划挪用五百万公款给自己做基延。他算过账：贪污最多判二十年，出狱后还有两百多年可活，划算，但一直犹豫。愚人节当天，同事搞恶作剧，伪造“IT共和国攻击金融系统、所有存款清零”的假消息，主角一度恐慌，反而被推着下了决心。他去找女友简简摊牌，结果简简先提出分手——她打算用更便宜的冬眠技术睡到未来，说“当我还年轻时，你已经老了”。主角终于下定决心，挪用公款购买基延。
