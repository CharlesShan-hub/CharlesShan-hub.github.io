# 不能共存的节日

## 阅读感受 - 2026-10-23

> 会有剧透哦~

又读了一遍，其实文章很好理解。就是一个外星人访问地球，第一个小故事说的是苏联宇航员上天，说这个是地球的诞生日。多年以后，这个外星人到了中国脑机接口实验室，那里刚实现了从大脑直接输出文字、不用手打，外星人说这一天是地球的流产日。其实他的意思是，人类一旦对虚拟世界沉迷，就会放弃对外的探索。现在这个思想已经十分普遍了。但是，这两个技术真的是互不相容的两个技术吗，我可以理解大刘担心人类沉迷虚拟的这个方向，但我对二选一的绝对主义保留观点。

这篇文章写于2016年，那时候还没有大模型，脑机接口概念很热但还没真正做出来。小说里的案例是从大脑读出文字输出到电脑，但这个技术并不能代表“意识上传虚拟世界”那个终极目标。相对而言，从大脑读出文字已经有可行路径，而把语义写进大脑几乎没有成熟方法，因为那是高语义信息的任务。

换个角度想，脑机接口就一定是坏的吗？其实不然。2025年5月“北脑一号”把大脑信号经芯片传到腿部，让瘫痪多年的病人重新站了起来。它走的是修复身体连接的路，不是把人抽离现实的路。可见脑机接口并没有让人失去对宇宙的探索，两者确实可以共存——中国目前还计划登陆月球。

大家潜意识里容易把世界当成沿当前轨迹直线发展，而不是动态变化的。比如小时候说发展工业就会破坏环境，要是告诉那时候的我们，现在环境保护已经提到国策级别的高度，一定很难相信。另一个例子是，大家都觉得化石能源一定枯竭，石油会贵到没人开得起车，最后社会崩溃。但没人料到新能源发展这么快，中国新能源汽车的新增数量已经超过了燃油车。总的来说，这篇文章能看出大刘对世界发展的反思，但局限也很明显：他的担心今天看仍然成立，问题在于他把技术路径和社会反应都设成了单行道。他写的是思想实验，不是预测；思想实验需要极端设定才有力，但读者不必把极端设定当成必然结局。

《不能共存的节日》写于2016年，是刘慈欣应“不存在日报”第一届科幻春晚接龙活动约稿而写的短篇，也是他在《三体》之后发表的第一个短篇。故事的主角是一个伪装成普通工人的外星观察者G，他的任务是考察地球文明，寻找真正有意义的“节日”。在他看来，人类那些基于习俗和宗教的节日都不重要，真正值得标记的是物种进化中的关键节点，比如细胞分裂、生物上岸、直立行走、取火。

第一个故事发生在1961年4月12日，苏联宇航员加加林进入太空的那天。G在拜克努尔航天基地找到总设计师科罗廖夫，跟他喝了一杯酒，告诉他这一天有可能被命名为人类的“诞生节”，因为人类终于开始走向宇宙。但G同时也说，这只是“暂定”，还要看后续发展。

第二个故事跳到2050年。G出现在中国科学院脑科学与人机工程研究中心，那里刚实现了人脑与计算机的直接连接，下一步就是把人的记忆、意识和全部人格上载到网络中，让人可以生活在虚拟世界里，“想什么就有什么”。G发出的信息是：1961年4月12日的“诞生节”疑似取消，2050年10月5日确定成为重大节日，暂命名“流产节”。小说的意思很直白：人类一旦沉溺于虚拟世界，就不再向外探索宇宙，文明等于在摇篮里流产了。两个节日不能共存，选了这个就没有那个。
