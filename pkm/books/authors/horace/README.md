# 贺拉斯

> - 原名：Horace
> - 生卒：前65–前8
> - 国籍/朝代：古罗马·帝国时期
> - 体裁/流派：诗歌、抒情诗
> - 分类：B
> - 书目数：2

## 简介

贺拉斯（前65—前8）是奥古斯都时期杰出的抒情诗人、讽刺诗人和文艺评论家。早期作品《讽刺诗集》和《长短句集》嘲笑罗马社会的吝啬、贪婪与淫靡之风，宣扬中庸的生活哲学；《歌集》是其抒情诗的代表作，写醇酒、爱情、诗歌、友谊等。文学批评代表作《诗艺》继承亚里士多德的模仿说，提出"寓教于乐"的原则，主张创作学习古典、形式讲究完美，在古典主义时期被视为经典。
