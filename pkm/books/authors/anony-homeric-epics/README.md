## 简介

《伊利昂纪》（又译《伊利亚特》）与《奥德修纪》（又译《奥德赛》）是古希腊的两大史诗，相传由诗人荷马所作，故称荷马史诗。史诗记载了关于特洛伊战争的英雄传说，被视为古希腊文学辉煌的代表、欧洲叙事诗的典范。《伊利昂纪》写希腊联军围攻特洛伊城的十年战争，以阿基琉斯的愤怒为主线；《奥德修纪》写英雄奥德修斯战后归乡的历险。史诗塑造了众多英雄形象，故又称"英雄史诗"，表现了古希腊个体本位的文化价值观念，是西方悲剧意识的源头。
