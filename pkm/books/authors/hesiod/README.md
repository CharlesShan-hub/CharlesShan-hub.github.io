# 赫西俄德

> - 原名：Hesiod
> - 生卒：约前8世纪–约前7世纪
> - 国籍/朝代：古希腊·古风时期
> - 体裁/流派：诗歌、史诗
> - 分类：B
> - 书目数：2

## 简介

赫西俄德（约前8世纪末—前7世纪初）是荷马史诗之后古希腊著名的叙事诗人。原籍小亚细亚，后移居比奥细亚务农。长诗《工作与时日》（又译《农作与日子》）是教诲诗，规劝弟弟走正直劳动之路，讲述金、银、铜、英雄、铁五个时代，并通过"老鹰和夜莺"的寓言反映氏族贵族欺凌小农的现实，后半部以亲历感受描绘了丰富多彩的农村生活；另一长诗《神谱》叙述诸神由来，是最早关于宇宙起源与神的谱系的系统描述。
