# 卢克莱修

> - 原名：Lucretius
> - 生卒：约前99–约前55
> - 国籍/朝代：古罗马·共和国时期
> - 体裁/流派：诗歌、哲理诗
> - 分类：B
> - 书目数：1

## 简介

卢克莱修（约前98—前55）是罗马共和末期的诗人。他的《论自然》是一部说教性的诗作，用六音步格写成，着重阐述伊壁鸠鲁的哲学思想，间接介绍了德谟克利特的原子论，表述了物质不灭、凡人不必惧怕死亡的生活观。维吉尔称他知晓事物的起因，是个"幸福的人"。
