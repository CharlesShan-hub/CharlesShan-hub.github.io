# 亚里士多德

> - 原名：Aristotle
> - 生卒：前384–前322
> - 国籍/朝代：古希腊·古典时期
> - 体裁/流派：哲学、伦理学
> - 分类：B
> - 书目数：1

## 简介

亚里士多德（前384—前322）是古希腊哲学家，柏拉图的学生。他继承了柏拉图的模仿说，认为文艺的本质是模仿现实，并肯定现实与文艺都是真实的，因而肯定文艺具有认识作用和教育作用，其理论与后来的现实主义文学有密切联系。主要著作《诗学》。
