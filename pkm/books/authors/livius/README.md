# 利维乌斯

> - 原名：Livius Andronicus
> - 生卒：约前284–约前204
> - 国籍/朝代：古罗马·共和国时期
> - 体裁/流派：戏剧、悲剧
> - 分类：B
> - 书目数：2

## 简介

利维乌斯·安德罗尼库斯（约前280—前204）是生活在公元前3世纪的希腊人，古罗马文学的奠基人。他翻译（或编译）了荷马的《奥德修纪》，译介了古希腊抒情诗，并于公元前240年编译了一出古希腊悲剧和一出新喜剧，把古希腊文学的某些主要形式移栽到了缺少书面文学传统的罗马。他还创作取材于罗马历史的剧作，写过史诗《布匿战争》，为维吉尔撰写《埃涅阿斯纪》提供了有价值的参考。
