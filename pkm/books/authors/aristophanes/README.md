# 阿里斯托芬

> - 原名：Aristophanes
> - 生卒：约前446–前386
> - 国籍/朝代：古希腊·古典时期
> - 体裁/流派：戏剧、喜剧
> - 分类：B
> - 书目数：5

## 简介

阿里斯托芬（约前445—前385）是雅典旧喜剧诗人，也是唯一有完整作品传世的旧喜剧作家。一生写过44出喜剧，传世11出，多为政治讽刺剧，词锋犀利，想象力丰富。代表作《鸟》是现存最长的诗剧（1765行），被视为旧喜剧的精品。
