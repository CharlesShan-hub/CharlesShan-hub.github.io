# 普劳图斯

> - 原名：Plautus
> - 生卒：约前254–前184
> - 国籍/朝代：古罗马·共和国时期
> - 体裁/流派：戏剧、喜剧
> - 分类：B
> - 书目数：2

## 简介

普劳图斯（约前254—前184）是罗马共和时期的喜剧诗人，在文学领域集中精力只从事译编古希腊新喜剧的工作。他的改编大刀阔斧，有意识地选用和"改造"某些场段以适合罗马观众的欣赏口味，行文泼辣、果敢，用词机警，形式多变，善用双关语。
