# 索福克勒斯

> - 原名：Sophocles
> - 生卒：约前496–前406
> - 国籍/朝代：古希腊·古典时期
> - 体裁/流派：戏剧、悲剧
> - 分类：B
> - 书目数：5

## 简介

索福克勒斯（约前496—前406）是古希腊三大悲剧家之一。他将演员增至三位，一生写过123出剧作、24次获胜，现存7部。代表作《俄底浦斯王》被亚里士多德尊为悲剧典范，表现人的意志与命运的矛盾冲突，故称"命运悲剧"；结构精妙，并注重人物性格的刻画。
