# 萨福

> - 原名：Sappho
> - 生卒：约前630–约前570
> - 国籍/朝代：古希腊·古风时期
> - 体裁/流派：诗歌、抒情诗
> - 分类：B
> - 书目数：1

## 简介

萨福（约前612—?）是古希腊独唱体抒情诗的代表诗人，共写过9卷诗，流传甚少。她的诗多半是抒发个人感情的爱情诗，咏叹恋爱的痛苦与欢乐，也有歌颂母爱与缅怀友情的诗，语言朴素自然，感情真挚，音乐性强，被柏拉图称为"第十位文艺女神"。
