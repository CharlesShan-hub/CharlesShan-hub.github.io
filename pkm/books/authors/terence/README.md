# 泰伦提乌斯

> - 原名：Terence
> - 生卒：约前195–约前159
> - 国籍/朝代：古罗马·共和国时期
> - 体裁/流派：戏剧、喜剧
> - 分类：B
> - 书目数：3

## 简介

泰伦提乌斯（约前190—前159）是罗马共和时期的喜剧诗人，偏好铺排双重情节，擅长细节的处理。他立意中庸，风格优雅，通过善良的主人、忠诚的奴隶、慈爱的父亲等形象，集中而突出地表现了新喜剧的人文情调。
