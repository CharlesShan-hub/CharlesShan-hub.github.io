# 阿加莎·克里斯蒂

> - 书目数：84

## 简介

阿加莎·克里斯蒂（Agatha Christie，1890—1976），英国侦探小说家、剧作家，无可争议的"侦探小说女王"。创作生涯五十余年，著有八十余部侦探小说，销量仅次于《圣经》和莎士比亚，开创了侦探文学史上的"黄金时代"。笔下两大侦探——小胡子比利时侦探赫尔克里·波洛与乡村老小姐马普尔小姐家喻户晓，《罗杰疑案》《东方快车谋杀案》《尼罗河上的惨案》《无人生还》皆为传世经典。1971 年获英国女王册封爵士称号。

代表作按系列分：波洛系列（斯泰尔斯庄园奇案、罗杰疑案、东方快车谋杀案、ABC谋杀案、尼罗河上的惨案、帷幕等）、马普尔小姐系列（寓所谜案、谋杀启事、复仇女神等）、汤米与塔彭丝系列（暗藏杀机、煦阳岭的疑云等），以及无人生还、怪屋、长夜等非系列名作和黑咖啡等剧本、自传。
