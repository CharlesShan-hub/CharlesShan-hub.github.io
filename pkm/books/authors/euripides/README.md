# 欧里庇德斯

> - 原名：Euripides
> - 生卒：前480–前406
> - 国籍/朝代：古希腊·古典时期
> - 体裁/流派：戏剧、悲剧
> - 书目数：18

## 简介

欧里庇得斯（约前484—前406）是古希腊三大悲剧家之一，青年时代师从哲学家阿那克萨戈拉。一生写92出悲剧，现存19出。代表作《美狄亚》通过血腥的家庭复仇提出"妇女地位"的社会问题；他擅长描写悲苦场景与人物心理，被亚里士多德称为最擅长编写悲苦场景的诗人，对后世影响很大。
