# 伊索

> - 原名：Aesop
> - 生卒：约前620–前564
> - 国籍/朝代：古希腊·古风时期
> - 体裁/流派：寓言、散文
> - 分类：B
> - 书目数：1

## 简介

相传伊索是古希腊的一个奴隶，《伊索寓言》即因他而得名。寓言以动物生活为主要内容，运用拟人手法，表现下层平民和奴隶的思想情感，是他们的生活教训和斗争经验的总结，名篇有《狼和小羊》《狐狸与葡萄》《农夫与蛇》等，对后来法国拉封丹、德国莱辛、俄国克雷洛夫的寓言创作都产生过影响。
