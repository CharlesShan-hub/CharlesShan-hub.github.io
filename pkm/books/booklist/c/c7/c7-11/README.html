明代词曲与民歌

共 0 本 · 已读 0 · 未读 0

父书单：明清文学

从文学史的发展来看，词的高峰在宋代，曲的高峰在元代，明代的词和散曲相比前代已发生蜕变，走向衰落。与此同时，民歌作为一种流行于市井的艺术形式，在明代中后期获得了迅速发展，活泼生动地反映出明代社会生活的丰富性与多面性。

第一节 明词

明代既少有影响的词人，又乏流传后世的经典词作，但就一代词史而言，明词自有值得探索之处。

明初词人大多由元入明，如杨基、张肯、瞿佑、张以宁、贝琼、魏观、凌云翰等人，其中以刘基、高启成就较高。刘基词集名《写情集》，共四卷，收词二百四十二首。其小令清新雅丽，而更能体现其才情和气格的是长调。高启存词三十馀首，名为《扣舷集》，多属慷慨激昂之声。如他二十五岁时所作《念奴娇·自述》一词，字里行间充溢着壮志未酬的感慨。后人评论其词，“大致以疏旷见长”（《古今词话》），“信笔写去，不留滞于古，别有高境”（陈廷焯《云韶集》卷十二）。

永乐以至成化年间，台阁体文风笼罩文坛，词的创作也趋于没落。当时较有影响的词人有马洪、聂大年等人。

正德、嘉靖年间，明词迎来中兴，较著名的词人有杨慎、夏言、吴子孝、陈霆、张縫、陈铎等。王世贞《艺苑卮言》附录一称“我明以词名家者”有三人，除刘基之外，另外两人为杨慎和夏言。陈铎则被清季词学大家况周颐推为“全明不能有二”（《蕙风词话》卷五）的作家。

杨慎在明代以博学著称，著述极富，仅词选、词论著作就有《批点草堂诗馀》《词林万选》《百琲明珠》《古今词英》《填词选格》《词苑增奇》《填词玉屑》《诗馀辑要》《词品》等。杨慎存词较多，见于钱允治《类编笺释国朝诗馀》的达一百一十馀首。所作词在声韵等方面虽不尽合法度，但格调、意味能得五代之遗。他那些吟咏自身遭际的词作，总是饱含着切身感受。如《临江仙·戍云南江陵别内》：

楚塞巴山横渡口，行人莫上江楼。征骖去掉两悠悠。相看临远水，独自上孤舟。却羡多情沙上鸟，双飞双宿河洲。今宵明月为谁留？团团清影好，偏照别离愁。

杨慎嘉靖三年（1524）因“议大礼”触怒嘉靖皇帝，从此谪戍云南永昌卫，终身不获赦免。这首词是杨慎与续弦黄峨别离之作，情辞哀婉感人。

杨慎最著名的词作，自然是那首出现在毛评本《三国演义》开篇的《临江仙》：

滚滚长江东逝水，浪花淘尽英雄。是非成败转头空。青山依旧在，几度夕阳红。白发渔樵江渚上，惯看秋月春风。一壶浊酒喜相逢。古今多少事，都付笑谈中。

词见于杨慎所作《廿一史弹词》第三段说秦汉部分。就《廿一史弹词》各段的开篇词来看，均属吊古伤今、感时伤事之作。

陈霆（1479—1560前后）是一位理论与创作兼擅的词人。陈霆的词论著作有《渚山堂词话》三卷，论词以“圆妙”为宗。陈霆存词二百馀首，以长调居多，《四库全书总目》称其词“豪迈激越，犹有苏、辛遗范”。如《踏莎行·晚景》：

流水孤村，荒城古道，槎牙老木乌鸢噪。夕阳倒影射疏林，江边一带芙蓉老。风暝寒烟，天低衰草，登楼望极群峰小。欲将归信问行人，青山尽处行人少。

这首词写于安徽六安贬所。作者借秋日晚景之衰败凄清，抒发其沦落天涯的悲郁之情。结句化用欧阳修《踏莎行》“平芜尽处是春山，行人更在春山外”，而将思妇切换为游子，笔力健拔。

隆庆、万历以后，明代词坛颇不寂寞，既有兴之所至、以馀力作词的王世贞，又有风流自赏、肆力作词的施绍莘。而明代后期最为重要的词人群体，当属崇祯年间的云间词派，其中又以陈子龙为翘楚。

陈子龙论词，扬五代、北宋而抑南宋，推重“俊逸之韵”“深刻之思”“流畅之调”“秾丽之态”。其词亦多以“绵邈凄恻”见长。如《江城子·病起春尽》：

一帘病枕五更钟，晓云空，卷残红。无情春色，去矣几时逢？添我千行清泪也，留不住，苦匆匆。楚宫吴苑草茸茸，恋芳丛，绕游蜂。料得来年，相见画屏中。人自伤心花自笑，凭燕子，骂东风。

陈子龙身当明清易代之际，故国之思，兴亡之慨，时时聚集笔端。由词题来看，身当病起，又逢春尽，那种“留不住，苦匆匆”的无奈，“人自伤心花自笑”的痛切，看似伤春，实是伤时。

第二节 明代散曲

明代散曲虽然在作品数量方面超过元代，但其成就却不及元人。从发展历程来看，洪武至成化间散曲创作较为寥落，弘治以后，散曲才开始逐渐兴盛，其中如王磐、康海、陈铎、王九思、赵南星、冯惟敏、薛论道等人，均产生在明代中期以后。

明代散曲按风格不同可分为三派：冯惟敏、王九思、康海等继承马致远的为一派，王磐、金銮、施绍莘等继承张可久的为一派，梁辰鱼、沈璟、王骥德等崇尚文采格律的为一派。按照曲乐不同可分为南北两派：北派以冯惟敏为首，南派以施绍莘为首。明代散曲南北的分界比较明显，北曲的格调大体承自元代，以慷慨豪壮为主；南曲的格调大体表现为清柔婉媚，是在明代戏曲腔调的基础上发展起来并走向成熟的。

明前期散曲整体来说比较萧条，缺少名家名作。明初散曲作家如汤式、贾仲明、刘兑、唐复等人，多由元入明。成书于洪武末年的朱权的《太和正音谱》，曾列举“国朝一十六人”，大体包括了这一群体的主要散曲作家。在永乐以至成化间成就暗淡的散曲创作中，朱权、朱有燉、李昌祺等人算是较有影响的几位，其中又以朱有燉最为突出。和他的杂剧大多以庆赏、神仙道化为主题类似，其散曲常用于宴赏、赠答、酬和、庆贺等场合，尤其好作咏花之曲。格调虽然不高，但直至明代中期仍传唱不衰。李梦阳曾在《汴中元夕》（其三）中写道：“中山孺子倚新妆，郑女燕姬独擅场。齐唱宪王春乐府，金梁桥外月如霜。”牛恒（嘉靖十四年进士）诗《周藩王宫词》中也说：“唱彻宪王新乐府，不知明月下樊楼。”

由成化中后期以至嘉靖的八十馀年，是明代散曲的中兴期。从地域来说，南方曲家与北方曲家大体势均力敌；但从创作成就来看，北曲作家仍在南曲作家之上。康海、王九思等北方曲家擅长北曲自不必说；即便是南方曲家，在作品数量和创作水平上，也多是北曲胜过南曲。例如王磐，虽为扬州高邮（今江苏高邮）人，却以北曲知名，王骥德将他与徐渭、汤显祖并举，称为“今日词人之冠”；又如被称为“南词宗匠”的陈铎，存小令四百七十馀首，其中南曲仅七十馀首，存套数近百套，南曲仅占三分之一左右，其北曲的水平也在南曲之上。

明代中期曲坛，陈铎（约1488—约1521）曲名甚著。其散曲作品，以女子口吻言情、抒怀的俯拾皆是，多以《春情》《闺情》《风情》《别情》《怨情》《美人》《青楼》《香闺》《怨别》等为题。陈铎还有散曲集《滑稽馀韵》，共收小令一百四十一首，专咏市井生活的各种人物、场景和动态，宛如一幅世俗生活的长卷。不少作品写得形象生动、饶有趣味，如〔双调·雁儿落带过得胜令〕《机匠》等。

这一时期的北方曲家，名声最著的当属冯惟敏（1511—1580）。他的散曲集名《海浮山堂词稿》，共四卷。冯惟敏一生或隐居田园，或身处下僚，见于创作，虽不乏赠答、咏物、宴赏、应酬之作，但反映现实、叙写世态的作品明显增多。冯惟敏的散曲作品，风格上继承了北方散曲豪放雄壮的传统，辞气奔放，格调疏旷，因而有“曲中辛弃疾”之称。王世贞以“劲切雄丽”概括其散曲风格，并评价说：“北调……近时冯通判惟敏，独为杰出，其板眼务头、撺抢紧缓，无不曲尽，而才气亦足发之。”（《曲藻》）如〔南吕·一枝花〕《对驴弹琴》。俗语谓“对牛弹琴”，此曲题为“对驴弹琴”，寄寓知音难求、怀才不遇的感慨，而又不失幽默。

隆庆、万历以至明末是明代散曲的新变期，曲坛风气由此前的北曲盛行转而以南曲为主调。由曲乐演变而随之发生散曲风格变迁，是嘉靖以后曲坛的一个重要趋势，梁辰鱼（1519—1591）被认为是促成明代后期曲风转变的关键人物。

梁辰鱼的散曲集名《江东白苎》，正、续两集，各二卷，存小令五十四首，套数四十一套。曲调上主要借鉴了魏良辅改革后的昆腔。梁辰鱼曲风婉丽，长于套数，王骥德将他与陈铎并称，认为二人“最称烂漫”（《曲律》卷四）。所作散曲“雅裁丽制，含思宛转”（董康《江东白苎跋》），颇见才情，但也存在“多俗意陈语”的弊病。如〔夜行船〕《拟金陵怀古》，博采众典，几乎“无一字无来处”。与前辈作家相比，梁辰鱼的散曲在遣词造语上少了几分萧疏之气，而显得绮丽浓艳，在改变曲坛风气的同时，也使散曲进一步趋于雅化。凌濛初批评说：“盖其生嘉、隆间，正七子雄长之会，崇尚华靡；弇州公以维桑之谊，盛为吹嘘，且其实于此道不深，以为词如是观止矣，而不知其非当行也。……靡词如绣阁罗帏、铜壶银箭、黄莺紫燕、浪蝶狂蜂之类，启口即是，千篇一律。甚者使僻事，绘隐语，词需累诠，意如商谜，不惟曲家一种本色语抹杀无馀，即人间一种真情话，埋没不露矣。”（《谭曲杂札》）

明代后期散曲名家多以南曲见长，如沈璟、王骥德、张凤翼、冯梦龙、施绍莘等，甚至出现了沈璟家族这样四世业曲的曲学世家；而以写作北派散曲知名的曲家，仅有薛论道、赵南星等少数几人。影响所及，编选南曲集子的风气也盛行一时，如张楚叔、张旭初的《吴骚合编》、周之标的《吴歛萃雅》、冯梦龙的《太霞新奏》、凌濛初的《南音三籁》等，所选均以南曲为主。明代后期，曲论著作也蔚为大观，如魏良辅的《曲律》，王骥德的《曲律》，吕天成的《曲品》，祁彪佳的《远山堂曲品》，沈宠绥的《弦索辨讹》《度曲须知》等。

第三节 明代民歌

明代流行的民间歌曲，有“时尚小令”“时曲”“小调”“时调”“小唱”“小曲”“小词”“俚曲”“吴歌”“山歌”等多种不同称呼。民歌为曲中之俗调，比散曲更富于世俗意趣：第一，体制自由，韵律疏散，体式上无严格要求；第二，尚俗尚浅，以俚为贵；第三，自然真挚，贴近生活。明代民歌发展大致经历了由北到南的过程，风格也随之由雄劲旷放变为柔媚婉丽，演变轨迹与明代散曲基本一致。

明代民歌兴起于宣德、正统至成化、弘治年间，大体是南北并行而以北曲为盛的格局。南方民歌主要以吴地山歌为主，叶盛说：“吴人耕作，或舟行之劳，多作讴歌以自遣，名唱山歌。”（叶盛《水东日记》卷五“山歌”）陆容也说：“吴中乡村唱山歌，大率多道男女情致而已。”（陆容《菽园杂记》卷一）北方盛行的民歌，有〔锁南枝〕〔傍妆台〕〔山坡羊〕等曲，分别以《泥捏人》《鞋打卦》《熬髹髻》等为题。如〔锁南枝〕《泥捏人》：

傻俊角，我的哥，和块黄泥儿捏咱两个。捏一个儿你，捏一个儿我。捏的来一似活托，捏的来同床上歇卧。将泥人儿摔碎，着水儿重和过，再捏一个你，再捏一个我。哥哥身上也有妹妹，妹妹身上也有哥哥。

据李开先《词谑》记载，有人向李梦阳请教作诗之道，李梦阳教以“若似得传唱〔锁南枝〕，则诗文无以加矣”。何景明也称赞此曲是“时词中状元也”，将它与《国风》相提并论：“情词婉曲，有非后世诗人墨客操觚染翰、刻骨流血所能及者，以其真也。”

现存较早刊刻行世的民歌，是成化七年（1471）金台鲁氏所刻《新编四季五更驻云飞》《新编题西厢记咏十二月赛驻云飞》《新编太平时赛赛驻云飞》和《新编寡妇烈女诗曲》等四种，其中《新编四季五更驻云飞》一卷七十九首，《新编题西厢记咏十二月赛驻云飞》一卷七十三首，《新编太平时赛赛驻云飞》一卷四十首，《新编寡妇烈女诗曲》一卷，内容大多与男女情爱有关。

明代中后期的时尚小曲受到选家的广泛关注。正德、嘉靖时期刊刻的《盛世新声》《词林摘艳》《雍熙乐府》均收录民歌作品。万历以后，不断有民歌新曲被创制出来。范濂说：“歌谣词曲，自古有之，惟吾松近年特甚。凡朋辈谐谑，及府县士夫举措稍有乖张，即缀成歌谣之类，传播人口，而七字件尤多。至欺诳人处，必曰风云，而里中恶少燕闲，必群唱《银绞丝》《干荷叶》《打枣竿》，竟不知此风从何而起也。”（《云间据目钞》）万历时期的一些散曲选本，如黄文华的《词林一枝》、熊稔寰的《徽池雅调》、龚天我的《摘锦奇音》、陈所闻的《南北宫词纪》等，都收有一定数量的民歌时调。其中最为引人注目的民歌辑本，要属冯梦龙编辑的《挂枝儿》和《山歌》两种。二书的共同特点，用冯梦龙自己的话说，就是“借男女之真情，发名教之伪药”（《叙山歌》）。

《挂枝儿》十卷，又名《童痴一弄》，收录民歌四百一十九首，加上评注中注明改订的十六首，共四百三十五首，除少数为文人拟作外，主要是民间作品。《挂枝儿》大多属于南人依拟北方俗曲的时调小曲，其腔调源出于《打枣竿》，内容多表现江南情调。《山歌》十卷，又名《童痴二弄》，录民歌三百八十首，加上评注中注明的异文三首，共三百八十三首。收录范围基本属于吴地民歌，多为“野竖矢口寄兴之所为，荐绅学士家不道”的“私情谱”。郑振铎称之为“吴语文学的最大的发现”（《中国俗文学史》下卷）。

除了吟咏男女性情的作品，《挂枝儿》《山歌》中还有不少反映明代社会世相的篇章，如《挂枝儿·谑部·假纱帽》对买官卖官现象的抨击。又如《山歌》卷九《山人》一篇，对晚明山人的生活情态作了反讽式的描述：

说山人，话山人，说着山人笑杀人。（白）身穿着僧弗僧俗弗俗个沿落厂袖，头带子方弗方圆弗圆个进士唐巾。弗肯闭门家里坐，肆多多在土地堂里去安身。……〔驻云飞〕笑杀山人，终日忙忙着处跟，头戴无些正，全靠虚帮衬。唊，口里滴溜清，心肠墨锭。八句歪诗，尝搭公文进。今日胥门接某大人，明日阊门送某大人。

《四库全书总目提要》说：“山人墨客，莫盛于明之末年，刺取清言，以夸高致，亦一时风尚如是也。”（《增定玉壶冰》提要）《山人》一篇，所调侃的正是“一时风尚”。

明代中后期民歌的兴起，对文学理论和文人创作产生了不小的影响。理论层面，李梦阳说“真诗乃在民间”（《诗集自序》），李开先说“真诗只在民间”（《市井艳词序》），袁宏道也说“当代无文字，闾巷有真诗”（《答李子髯》）。袁宏道《叙小修诗》说民歌的精神本质是“真人所作，故多真声”，“任性而发”。创作方面，不少文人热心于写作拟民歌。如冯惟敏所作〔河西六娘子〕《笑园六咏》，就是具有浓郁民歌气息的文人拟作。刘效祖、赵南星、冯梦龙等人，也都有颇为出色的拟民歌作品。
